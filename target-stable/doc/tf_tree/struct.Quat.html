Expand description

Unit quaternion, Hamilton convention, scalar (w) first.

Represents an active rotation. Unchecked constructors and arithmetic assume (and preserve, up to rounding) unit norm.

INVARIANT: callers of unchecked constructors guarantee |q| == 1 within 1e-12.

pub fn normalize(self) -> Quat

Return this quaternion scaled to unit norm.

A zero quaternion (norm below 1e-300) is returned unchanged rather than producing infinities; unit-norm callers never hit that path.

Dot product of the four components, viewed as vectors in R⁴.

pub const fn neg(self) -> Quat

Negate every component. -q is the same rotation as q.

Component-wise scale.

Component-wise sum.

pub const fn sub(self, rhs: Quat) -> Quat

Component-wise difference.

Exists for the chord form |a − b|² = 2 − 2·(a·b), which is how slerp obtains the angle between two near-parallel quaternions without forming 1 − dot — a subtraction that cancels catastrophically exactly when the two are close, which is the case that dominates.

pub const fn vector(self) -> Vec3

The vector (imaginary) part (x, y, z).

pub const fn from_pure(v: Vec3) -> Quat

Build a pure quaternion (0, v) from a vector.

pub fn rotate(self, v: Vec3) -> Vec3

Rotate a vector by this (unit) quaternion: v' = q · v · q⁻¹.

Uses the two-cross-product form, which needs no explicit quaternion product and is numerically well behaved.
