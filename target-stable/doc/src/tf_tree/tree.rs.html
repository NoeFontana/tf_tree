1//! The concrete [`Tree`] (owning a heap arena), its [`TreeBuilder`], the
2//! per-edge [`Capacity`]/[`EdgeCfg`] declarations, and the `Display` wrapper
3//! [`Described`].
4//!
5//! Per decision `0004` (`docs/decisions/0004-builder-time-edge-declaration.md`,
6//! still authoritative for this API), the tree's topology is declared on the [`TreeBuilder`]
7//! *before* [`TreeBuilder::build`]. `build()` sizes the arena from exactly those
8//! declarations (via `ArenaLayout` / `from_edges` sizing), so the arena reserves
9//! ring slots **only** for dynamic edges, each sized to its own capacity. There
10//! is no post-build `declare_*`; the only runtime topology change is
11//! [`Tree::reparent`], which reuses an already-declared edge and allocates no new
12//! capacity.

35/// First backoff interval for this crate's two waits. Doubles up to
36/// [`MAX_BACKOFF`].
37///
38/// **One definition, and it is the facade's own** (`docs/decisions/0019` §2b).
39/// Both poll loops the record adds use it: [`Tree::await_frames`] here, and
40/// `crate::open::Open::await_open` one module over.
41///
42/// An earlier revision of this branch had it *twice* — widened to `pub` on
43/// `tf_tree_ipc` for `await_open`, and restated here behind a
44/// `const _: () = assert!(…)` equality check for `await_frames`, which cannot
45/// name `tf_tree_ipc` at all in a default build. That is two mechanisms for one
46/// pair of numbers, and the cost of the first is permanent public API on a crate
47/// that had no reason to grow any.
48///
49/// What the deleted assertion guaranteed was that these matched
50/// `tf_tree_ipc`'s *internal* handshake backoff, and that coupling was
51/// decorative rather than required: `await_open` retries whole `attempt()`
52/// calls, each of which runs the rendezvous' own retry loop inside it. They are
53/// nested loops over different work and nothing breaks if they disagree. The
54/// numbers are chosen for the same reason in both places — small enough that a
55/// takeover completing in a millisecond is joined promptly — not because one
56/// derives from the other.
57pub(crate) const MIN_BACKOFF: Duration = Duration::from_micros(200);
58/// Backoff ceiling for this crate's two waits; see [`MIN_BACKOFF`].
59pub(crate) const MAX_BACKOFF: Duration = Duration::from_millis(4);

61/// Why [`Tree::await_frames`] could not produce ids.
62///
63/// **Facade-local, and deliberately not a `Timeout` variant on
64/// [`LookupError`]** (`docs/decisions/0019`, and `0018` for the reasoning it
65/// inherits). A wall-clock concept does not belong in a `no_std` crate that
66/// `0018` keeps free of one, and adding the variant there would put an
67/// unreachable arm in the return type of every hot-path read.
68///
69/// `Copy`, `String`-free and `#[non_exhaustive]`, in the shape of
70/// `OpenError` — `docs/API.md` R5. (No intra-doc link: `OpenError` is
71/// behind the `shm` feature, and this type is not.)
72#[derive(Clone, Copy, Debug, PartialEq, Eq, thiserror::Error)]
73#[non_exhaustive]
74pub enum AwaitError {
75    /// The budget expired with at least one name still un-interned.
76    ///
77    /// **A hash, not a name**, for the same reason
78    /// [`LookupError::UnknownFrame`] carries one: a name that was never
79    /// interned has no [`FrameId`], and D11 keeps `String`s out of error types.
80    /// The caller still holds the `[&str; N]` it passed in, so it can recover
81    /// the name by hashing its own inputs — or read it out of
82    /// [`Tree::describe`]'s prose layer.
83    #[error("no frame with name hash {hash:#018x} appeared before the deadline")]
84    Timeout {
85        /// The 64-bit BLAKE3 prefix hash of the first name still missing.
86        hash: u64,
87    },
88    /// The tree is writable, and this call refuses to guess what that means.
89    ///
90    /// "Does this name exist" has two defensible answers on a writable tree,
91    /// because [`Tree::frame`] *interns on demand* there — a wait built on it
92    /// would return instantly, with a fresh id, for a name nobody declared.
93    /// `docs/decisions/0019` §3 forbids picking one silently, so this refuses
94    /// and points at [`Tree::frame`], which on a writable tree cannot fail for
95    /// absence and needs no wait at all.
96    ///
97    /// `#[non_exhaustive]` is what keeps relaxing this available later:
98    /// refusing now is the reversible direction.
99    #[error("await_frames refuses a writable tree; use Tree::frame, which interns on demand and cannot fail for absence")]
100    WritableTree,
101    /// The tree is a frozen `.tft` image, so no name will ever be interned into
102    /// it.
103    ///
104    /// The sibling of [`AwaitError::WritableTree`] and refused for the same
105    /// reason: a wait that cannot mean what the caller thinks should say so
106    /// rather than sleep. `docs/PHASE5.md` §2.4 makes a frozen arena
107    /// permanently read-only *and* writer-free, so this wait is futile by
108    /// construction — polling it would burn the caller's whole budget and then
109    /// report [`AwaitError::Timeout`], which is technically honest and
110    /// practically a lie: nothing was late, and waiting longer would not help.
111    ///
112    /// A frozen tree's frame table is complete the moment it opens, so the
113    /// right call is [`Tree::frames`] or a direct [`Tree::lookup`] — and
114    /// [`Tree::describe`] on the resulting [`LookupError::UnknownFrame`] lists
115    /// what the file actually contains.
116    #[error("await_frames refuses a frozen .tft tree: it has no writers, so no name can appear")]
117    FrozenTree,
118    /// A name resolved to an error rather than to an id.
119    ///
120    /// Terminal, not retried. [`FrameError::FrameHashCollision`] is a permanent
121    /// property of the two names involved, and [`FrameError::InternContended`]
122    /// names a claimant no caller can judge — waiting on either is waiting on
123    /// something that will not change on its own.
124    #[error("{0:?}")]
125    Frame(FrameError),
126    /// This tree belongs to a process that no longer exists — it was opened
127    /// before a `fork()` and this is the child. See [`Tree::detached`].
128    ///
129    /// Checked **every iteration**, before the arena is read: a detached tree
130    /// answers with the poison arena, whose `find_frame` says `Ok(None)` for
131    /// every name. Without the check a fork victim would wait out the whole
132    /// budget and then report a timeout for something that is not one.
133    #[error("this tree was opened before a fork() and is being used in the child")]
134    ChildDetached,
135}

137/// `[Option<FrameId>; N]` → `[FrameId; N]`, or `None` if any slot is empty.
138///
139/// [`FrameId`] has no `Default` and this crate denies `unwrap`/`expect`, so the
140/// array is seeded with a value obtained by `?` *inside* `Option`
141/// (`FrameId::new(1)` is `Some` because 1 is not the root sentinel) and every
142/// element is then overwritten from `found`. No allocation, and `N == 0`
143/// answers `Some([])`.
144fn all_interned<const N: usize>(found: &[Option<FrameId>; N]) -> Option<[FrameId; N]> {
145    let mut out = [FrameId::new(1)?; N];
146    for (dst, src) in out.iter_mut().zip(found.iter()) {
147        *dst = (*src)?;
148    }
149    Some(out)
150}

152/// A frame record's stored — and therefore possibly truncated — name.
153///
154/// `FrameRecord` keeps 48 bytes and a length; a longer name was cut at intern
155/// time and the cut is not recoverable here. `from_utf8_lossy` rather than a
156/// refusal, because a truncation can land mid-codepoint and a frame listing that
157/// fails on one bad byte tells the caller nothing about the other ninety frames.
158fn stored_name(bytes: &[u8], len: u8) -> String {
159    let n = (len as usize).min(bytes.len());
160    String::from_utf8_lossy(&bytes[..n]).into_owned()
161}

163/// Smallest power of two `>= n`, saturating at the largest `u32` power of two
164/// (`1 << 31`). `next_pow2(0) == 1`, so a dynamic ring is never zero-length (a
165/// zero capacity is what marks a *static* edge in the arena layout).
166fn next_pow2_u32(n: u32) -> u32 {
167    let mut p: u64 = 1;
168    let target = u64::from(n);
169    while p < target {
170        p <<= 1;
171    }
172    if p > u64::from(u32::MAX) {
173        1u32 << 31
174    } else {
175        p as u32
176    }
177}

179/// Ring capacity for one dynamic edge, always a power of two.
180///
181/// A capacity may be given directly with [`Capacity::slots`] (rounded up to a
182/// power of two) or as a retention window with [`Capacity::history`]. The window
183/// form is the documented default idiom: it is how operators reason about
184/// history depth ("keep 10 s at 1 kHz") and what URDF ingestion will feed.
185///
186/// ```
187/// use tf_tree::Capacity;
188/// assert_eq!(Capacity::slots(5000).get(), 8192);      // rounded up to 2^13
189/// assert_eq!(Capacity::history(1000.0, 10.0).get(), 16384); // next_pow2(10_000)
190/// ```
191#[derive(Clone, Copy, Debug, PartialEq, Eq)]
192pub struct Capacity(u32);
193
194impl Capacity {
195    /// A ring holding at least `n` samples, rounded **up** to a power of two.
196    #[must_use]
197    pub fn slots(n: u32) -> Capacity {
198        Capacity(next_pow2_u32(n))
199    }
200
201    /// A ring sized to retain `secs` seconds of history at `rate_hz`:
202    /// `next_pow2(ceil(rate_hz * secs))`. Non-finite or non-positive inputs
203    /// collapse to the minimum one-slot ring.
204    #[must_use]
205    pub fn history(rate_hz: f64, secs: f64) -> Capacity {
206        let needed = (rate_hz * secs).ceil();
207        let clamped = if needed.is_finite() && needed >= 1.0 {
208            if needed > f64::from(u32::MAX) {
209                u32::MAX
210            } else {
211                needed as u32
212            }
213        } else {
214            1
215        };
216        Capacity(next_pow2_u32(clamped))
217    }
218
219    /// The resolved power-of-two slot count.
220    #[inline]
221    #[must_use]
222    pub fn get(self) -> u32 {
223        self.0
224    }
225}

227/// Per-edge configuration for [`TreeBuilder::dynamic_edge`].
228///
229/// `capacity` is required; `interp` and `domain` fall back to the builder
230/// defaults ([`TreeBuilder::default_interp`] / [`TreeBuilder::default_domain`])
231/// when left `None`.
232///
233/// `#[non_exhaustive]` because this struct is *designed* to grow — `interp`,
234/// `domain` and `nominal_rate_mhz` all arrived after `capacity`, and each would
235/// have been a breaking change for any out-of-repo `EdgeCfg { .. }` literal.
236/// Construction goes through [`EdgeCfg::new`] and the builder methods, which
237/// stay source-compatible across every such addition. Reading the fields is
238/// unaffected.
239#[derive(Clone, Copy, Debug, PartialEq, Eq)]
240#[non_exhaustive]
241pub struct EdgeCfg {
242    /// Ring capacity (a power of two; see [`Capacity`]).
243    pub capacity: Capacity,
244    /// Interpolation policy; `None` uses the builder default.
245    pub interp: Option<InterpPolicy>,
246    /// Time-domain tag (see [`Domain`]); `None` uses the builder default.
247    pub domain: Option<u8>,
248    /// The rate this edge is *expected* to publish at, in milli-hertz;
249    /// `0` means "not declared". Set it through [`EdgeCfg::nominal_rate_hz`]
250    /// rather than by hand.
251    ///
252    /// Stored in `EdgeRecord::nominal_rate_mhz`, where `tf_tree doctor`'s
253    /// `TFT007` reads it. Nothing on the read path consults it: an edge that
254    /// publishes at half its declared rate still resolves normally, and saying
255    /// so is a diagnostic's job, not the lookup's.
256    pub nominal_rate_mhz: u32,
257}

272    /// Declare the rate this edge is expected to publish at, in hertz.
273    ///
274    /// This is the *nominal* rate — what the publisher was configured to do —
275    /// and is the only thing that makes "the observed rate is wrong" a
276    /// statement anybody can check. Without it a diagnostic can report what a
277    /// rate *is* and never that it should have been something else
278    /// (`docs/PHASE5.md` §6, `TFT007`).
279    ///
280    /// Stored as milli-hertz because the rates that matter span 0.1 Hz (a map
281    /// update) to 1 kHz (an IMU), which integer hertz cannot express at the low
282    /// end. A rate that is not finite, not positive, or beyond `u32::MAX` mHz
283    /// (~4.29 MHz) is **not** a rate any robot publishes at, so it is dropped
284    /// back to "not declared" rather than clamped: a clamp would invent a
285    /// 4.29 MHz nominal out of an `f64::INFINITY` typo and then report every
286    /// real sample as a deviation from it.
287    #[must_use]
288    pub fn nominal_rate_hz(mut self, rate_hz: f64) -> EdgeCfg {
289        let mhz = rate_hz * 1000.0;
290        self.nominal_rate_mhz = if mhz.is_finite() && mhz >= 1.0 && mhz <= f64::from(u32::MAX) {
291            // `round`, not `as`: `as` truncates, so a rate that arrived as
292            // 19.9999 Hz through a text round-trip would declare 19_999 mHz for
293            // an edge the operator wrote `20.0` for.
294            mhz.round() as u32
295        } else {
296            0
297        };
298        self
299    }
300
301    /// Override the interpolation policy for this edge.
302    #[must_use]
303    pub fn interp(mut self, interp: InterpPolicy) -> EdgeCfg {
304        self.interp = Some(interp);
305        self
306    }
307
308    /// Override the time-domain tag for this edge.
309    #[must_use]
310    pub fn domain(mut self, domain: u8) -> EdgeCfg {
311        self.domain = Some(domain);
312        self
313    }
314}

334/// Builder for a [`Tree`].
335///
336/// Collect the topology — frames and static/dynamic edges — then call
337/// [`Self::build`]. `build()` derives the arena's frame and edge budgets from
338/// exactly what was declared (plus the reserved id-0 sentinels and any optional
339/// headroom) and reserves ring slots only for the dynamic edges.
340///
341/// ```
342/// use tf_tree::{TreeBuilder, Capacity, EdgeCfg, Iso3};
343///
344/// let tree = TreeBuilder::new()
345///     .dynamic_edge("odom", "base_link", EdgeCfg::new(Capacity::history(50.0, 10.0)))
346///     .static_edge("base_link", "camera", &Iso3::IDENTITY)
347///     .build()
348///     .expect("layout");
349/// ```

351pub struct TreeBuilder {
352    default_interp: InterpPolicy,
353    default_domain: u8,
354    frames: Vec<String>,
355    edges: Vec<EdgeDecl>,
356    frame_headroom: u32,
357    edge_headroom: u32,
358}

447    /// Allocate the arena from the declared topology and build the tree.
448    ///
449    /// The frame budget is `unique_frames + 1` (slot 0 is the root sentinel) and
450    /// the edge budget is `edges + 1` (`EdgeId 0` is the "no edge" sentinel), each
451    /// plus any headroom. Ring slots are reserved only for dynamic edges, sized to
452    /// their own capacities and laid out at cumulative offsets in `EdgeId` order.
453    ///
454    /// # Errors
455    ///
456    /// [`BuildError`] if two edges share a child, the declared counts overflow the
457    /// `u32` id space, the capacities do not form a valid arena layout (e.g. the
458    /// arena would exceed the `u32` offset model), a frame name collides on its
459    /// 64-bit hash, or an edge would create a cycle.
460    pub fn build(self) -> Result<Tree, BuildError> {
461        let arena = self
462            .build_with(|layout, pid, start, boot| Ok(HeapArena::new(layout, pid, start, boot)))?;
463        let backing = ArenaBacking::Heap(arena);
464        let (participant, incarnation) = register_participant(&ArenaView::new(backing.as_dyn()))
465            .map_err(BuildError::Participant)?;
466        let liveness = liveness_for(ArenaView::new(backing.as_dyn()).header().boot_id);
467        #[cfg(all(feature = "shm", target_os = "linux"))]
468        let fork_gen = fork_gen_for(&backing);
469        Ok(Tree {
470            // Before `backing` moves into `arena`.
471            cache_scope: cache_scope_for(&backing),
472            arena: backing,
473            participant,
474            incarnation,
475            liveness,
476            decl: Mutex::new(()),
477            #[cfg(all(feature = "shm", target_os = "linux"))]
478            attachment: None,
479            #[cfg(all(feature = "shm", target_os = "linux"))]
480            claim_lock: None,
481            #[cfg(all(feature = "shm", target_os = "linux"))]
482            ofd_probe: None,
483            #[cfg(all(feature = "shm", target_os = "linux"))]
484            fork_gen,
485        })
486    }

488    /// Build the tree into a **shared-memory** segment instead of the heap.
489    ///
490    /// The returned [`Tree`] behaves identically — the read path does not know
491    /// which backend it has (`docs/PHASE2.md` §4) — but its arena lives in a
492    /// sealed `memfd` that other processes can map with [`Tree::attach_shared`].
493    /// Hand them [`Tree::shared_fd`].
494    ///
495    /// `name` is a debug label only; it appears in `/proc/<pid>/fd` and is
496    /// truncated past 63 bytes. Segments are **not** discoverable by name — the
497    /// fd is the capability, which is what keeps an unrelated process from
498    /// attaching by guessing.
499    ///
500    /// # Errors
501    ///
502    /// [`BuildError`] as for [`TreeBuilder::build`], plus
503    /// [`BuildError::Shm`] if the segment could not be created, sized, mapped or
504    /// sealed.
505    #[cfg(all(feature = "shm", target_os = "linux"))]
506    pub fn build_shared(self, name: &str) -> Result<Tree, BuildError> {
507        let arena = self.build_with(|layout, pid, start, boot| {
508            MappedArena::create(name, layout, pid, start, boot).map_err(BuildError::Shm)
509        })?;
510        // **After** `build_with`, not inside `create` (§7.1). Population is at
511        // declaration granularity, and at `create` time nothing is declared yet
512        // — `frame_count` and `edge_count` are still zero, so `populate_hot`
513        // would fault in the header and stop. `build_with` is what interns the
514        // frames and declares the edges, so this is the first moment the arena
515        // can say what is actually in use.
516        arena.populate_hot();
517        let backing = ArenaBacking::Mapped(arena);
518        let (participant, incarnation) = register_participant(&ArenaView::new(backing.as_dyn()))
519            .map_err(BuildError::Participant)?;
520        let liveness = liveness_for(ArenaView::new(backing.as_dyn()).header().boot_id);
521        #[cfg(all(feature = "shm", target_os = "linux"))]
522        let fork_gen = fork_gen_for(&backing);
523        Ok(Tree {
524            // Before `backing` moves into `arena`.
525            cache_scope: cache_scope_for(&backing),
526            arena: backing,
527            participant,
528            incarnation,
529            liveness,
530            decl: Mutex::new(()),
531            #[cfg(all(feature = "shm", target_os = "linux"))]
532            attachment: None,
533            #[cfg(all(feature = "shm", target_os = "linux"))]
534            claim_lock: None,
535            #[cfg(all(feature = "shm", target_os = "linux"))]
536            ofd_probe: None,
537            #[cfg(all(feature = "shm", target_os = "linux"))]
538            fork_gen,
539        })
540    }

542    /// The shared body of [`TreeBuilder::build`] and
543    /// [`TreeBuilder::build_shared`]: everything except *which* allocation the
544    /// bytes land in.
545    ///
546    /// Generic over the backend rather than duplicated, because the moment the
547    /// two paths differ by a line, the heap and shared arenas stop being the
548    /// same bytes — and "the same bytes, read by the same code" is the entire
549    /// claim of Phase 2.
550    fn build_with<A: Arena>(
551        self,
552        make: impl FnOnce(&ArenaLayout, u32, u64, [u8; 16]) -> Result<A, BuildError>,
553    ) -> Result<A, BuildError> {
554        // 1. Unique frame names in first-seen order (explicit frames, then edge
555        //    endpoints). Order only affects id assignment, not correctness.
556        let mut names: Vec<&str> = Vec::new();
557        let mut seen: HashSet<&str> = HashSet::new();
558        for f in &self.frames {
559            if seen.insert(f.as_str()) {
560                names.push(f.as_str());
561            }
562        }
563        for e in &self.edges {
564            if seen.insert(e.parent.as_str()) {
565                names.push(e.parent.as_str());
566            }
567            if seen.insert(e.child.as_str()) {
568                names.push(e.child.as_str());
569            }
570        }
571
572        // 2. A frame is the child of at most one edge (it is a tree).
573        let mut children: HashSet<&str> = HashSet::new();
574        for e in &self.edges {
575            if !children.insert(e.child.as_str()) {
576                return Err(BuildError::DuplicateEdge {
577                    child: blake3_64(&e.child),
578                });
579            }
580        }
581
582        // 3. Budgets: declared count + reserved id-0 sentinel + optional headroom.
583        let frame_count = names.len() as u64;
584        let edge_count = self.edges.len() as u64;
585        let max_frames = frame_count + 1 + u64::from(self.frame_headroom);
586        let max_edges = edge_count + 1 + u64::from(self.edge_headroom);
587        let max_frames = u32::try_from(max_frames).map_err(|_| BuildError::TooManyFrames)?;
588        let max_edges = u32::try_from(max_edges).map_err(|_| BuildError::TooManyEdges)?;
589
590        // 4. Per-edge capacities indexed by EdgeId: index 0 (and any headroom
591        //    slots) is a zero-capacity sentinel; static edges are zero; dynamic
592        //    edges reserve their own capacity.
593        let mut caps = std::vec![0u32; max_edges as usize];
594        for (i, e) in self.edges.iter().enumerate() {
595            if let EdgeDeclKind::Dynamic(cfg) = &e.kind {
596                caps[i + 1] = cfg.capacity.get();
597            }
598        }
599
600        // 5. Size and allocate the arena. Declaration-time edge writes go through
601        //    an `ArenaBuilder`, whose `&mut` borrow of the arena is what makes
602        //    them sound: no shared `ArenaView` can exist while one happens.
603        let layout = ArenaLayout::new(max_frames, max_edges, caps)?;
604        let boot_id = boot_id();
605        let mut arena = make(
606            &layout,
607            std::process::id(),
608            process_start_time().unwrap_or(UNKNOWN_START_TIME),
609            boot_id,
610        )?;
611        // Scoped so the builder's exclusive borrow ends before `arena` moves into
612        // the `Tree`; nothing may declare an edge once the tree is shareable.
613        {
614            let mut builder = ArenaBuilder::new(&mut arena);
615            // Record how many edge slots are in use (sentinel + declared); nothing
616            // on the read path depends on it, but it keeps diagnostics honest.
617            builder
618                .view()
619                .header()
620                .edge_count
621                .store(edge_count as u32 + 1, Ordering::Relaxed);
622
623            // 6. Intern every frame name so isolated frames get an id and any
624            //    collision / over-capacity surfaces now. Interning is idempotent,
625            //    so the edge loop below re-interns endpoints to recover their ids.
626            for &n in &names {
627                builder.view().intern(n).map_err(BuildError::Frame)?;
628            }
629
630            // 7. Declare each edge (real ids start at 1) and wire the topology.
631            //    Each dynamic edge's ring occupies a cumulative slot range in
632            //    EdgeId order, so `running_off` is the element offset shared by its
633            //    stamp and pose sub-arenas (which have equal slot counts).
634            let mut running_off: u32 = 0;
635            for (i, e) in self.edges.iter().enumerate() {
636                let edge_id = (i + 1) as u32;
637                // Idempotent: both endpoints were interned in step 6.
638                let parent = builder
639                    .view()
640                    .intern(&e.parent)
641                    .map_err(BuildError::Frame)?;
642                let child = builder.view().intern(&e.child).map_err(BuildError::Frame)?;
643                let record = match &e.kind {
644                    EdgeDeclKind::Static(iso) => EdgeRecord::static_edge(
645                        parent.get(),
646                        child.get(),
647                        iso.to_bits(),
648                        self.default_domain,
649                    ),
650                    EdgeDeclKind::Dynamic(cfg) => {
651                        let capacity = cfg.capacity.get();
652                        let interp = cfg.interp.unwrap_or(self.default_interp);
653                        let domain = cfg.domain.unwrap_or(self.default_domain);
654                        let mut record = EdgeRecord::dynamic(
655                            parent.get(),
656                            child.get(),
657                            capacity,
658                            running_off,
659                            running_off,
660                            interp.as_u8(),
661                            domain,
662                        );
663                        // Assigned rather than passed to `dynamic()`: that
664                        // constructor is already at clippy's seven-argument
665                        // limit, and the field is plain data with no invariant
666                        // tying it to the ring layout the constructor computes.
667                        // Declaration time is the only moment it can be written
668                        // — `ArenaBuilder`'s `&mut` borrow ends with this scope,
669                        // and after that the arena may be shared.
670                        record.nominal_rate_mhz = cfg.nominal_rate_mhz;
671                        running_off += capacity;
672                        record
673                    }
674                };
675                builder
676                    .declare_edge(EdgeId(edge_id), record)
677                    .map_err(BuildError::Topology)?;
678                builder
679                    .view()
680                    .topology()
681                    .set_parent(child, parent.get(), edge_id)
682                    .map_err(BuildError::Topology)?;
683            }
684        }
685
686        Ok(arena)
687    }
688}

690/// Which allocation backs a [`Tree`]'s arena.
691///
692/// An enum rather than `Box<dyn Arena>` so the backend stays a concrete,
693/// statically-known type and no allocation is added to construct a tree. The
694/// read path is unaffected either way: [`ArenaView`] already takes
695/// `&dyn Arena`, and it is built once per [`Tree::guard`], not per lookup.
696enum ArenaBacking {
697    /// Single-process: one heap allocation (Phase 1).
698    Heap(HeapArena),
699    /// Multi-process: a sealed `memfd` mapped `MAP_SHARED` (Phase 2).
700    #[cfg(all(feature = "shm", target_os = "linux"))]
701    Mapped(MappedArena),
702    /// Offline: the arena image inside a `.tft`, mapped `PROT_READ`
703    /// (`docs/PHASE5.md` §2).
704    #[cfg(all(feature = "shm", target_os = "linux"))]
705    Frozen(tf_tree_arena::FrozenArena),
706}
707
708impl ArenaBacking {
709    fn as_dyn(&self) -> &dyn Arena {
710        match self {
711            ArenaBacking::Heap(a) => a,
712            #[cfg(all(feature = "shm", target_os = "linux"))]
713            ArenaBacking::Mapped(a) => a,
714            #[cfg(all(feature = "shm", target_os = "linux"))]
715            ArenaBacking::Frozen(a) => a,
716        }
717    }
718
719    /// Whether the mapping accepts stores.
720    ///
721    /// Every mutating entry point on [`Tree`] consults this. A `PROT_READ`
722    /// mapping does not fault politely on a `compare_exchange` — it delivers
723    /// `SIGSEGV`, killing the consumer process. Turning that into an `Err` is
724    /// the difference between read-only being a safety boundary and being a
725    /// loaded gun.
726    fn is_writable(&self) -> bool {
727        match self {
728            ArenaBacking::Heap(_) => true,
729            #[cfg(all(feature = "shm", target_os = "linux"))]
730            ArenaBacking::Mapped(a) => a.is_writable(),
731            // `docs/PHASE5.md` §2.4: a frozen arena's `AttachMode` is implicitly
732            // and permanently `ReadOnly`. There is no mode in which this can be
733            // true — the mapping is `PROT_READ`, so a store through it is a
734            // `SIGSEGV` and not an error anything can catch.
735            #[cfg(all(feature = "shm", target_os = "linux"))]
736            ArenaBacking::Frozen(_) => false,
737        }
738    }
739
740    /// Whether other processes may be mapping the same arena.
741    fn is_shared(&self) -> bool {
742        match self {
743            #[cfg(all(feature = "shm", target_os = "linux"))]
744            ArenaBacking::Mapped(_) => true,
745            // Other *processes* may map the same `.tft`, but "shared" here asks
746            // whether a peer can mutate it — the participant table, the claim
747            // protocol and reaping all hang off this answer. A frozen arena has
748            // no writers at all (§2.4), so it is `false` for the same reason a
749            // heap arena is.
750            #[cfg(all(feature = "shm", target_os = "linux"))]
751            ArenaBacking::Frozen(_) => false,
752            ArenaBacking::Heap(_) => false,
753        }
754    }
755
756    /// Whether this arena is a `.tft` image rather than something a process
757    /// could still be writing to.
758    ///
759    /// **Not derivable from the other two.** `is_writable() == false` is also
760    /// true of a live `PROT_READ` attachment, and `is_shared() == false` is also
761    /// true of a heap arena; only the pair identifies a frozen one, and a
762    /// predicate spelled as a conjunction of two unrelated answers is one
763    /// backing variant away from being wrong. [`Tree::await_frames`] is the
764    /// caller: a wait on a frozen tree is futile *by construction* — §2.4 says
765    /// a frozen arena has no writers at all — and futility that is statically
766    /// known should be an answer, not a nap.
767    fn is_frozen(&self) -> bool {
768        match self {
769            #[cfg(all(feature = "shm", target_os = "linux"))]
770            ArenaBacking::Frozen(_) => true,
771            #[cfg(all(feature = "shm", target_os = "linux"))]
772            ArenaBacking::Mapped(_) => false,
773            ArenaBacking::Heap(_) => false,
774        }
775    }
776}

778/// A claimed edge: the arena record, and the lease that makes its holder's
779/// death observable (`docs/PHASE2.md` §6.1, `docs/decisions/0005` §5).
780///
781/// Derefs to the [`Publisher`], so `push` and friends work unchanged.
782///
783/// # Drop order is load-bearing
784///
785/// The fields below are declared **publisher first, `_lease` second**, and Rust
786/// drops struct fields in declaration order. That yields *clear the record,
787/// then unlock* — the order `0005` §5 specifies.
788///
789/// Reversing it is not catastrophic but is wrong: it leaves a window in which
790/// the byte is free while the record still says held, which is precisely the
791/// signature a reaper reads as "the holder is dead". The reap that follows is
792/// harmless (our own release is a CAS and cannot clear a successor's claim) but
793/// it is a spurious epoch bump and a `ClaimRevoked` somebody has to explain.
794///
795/// This is not enforced by `ManuallyDrop`, and deliberately still is not.
796/// Doing so needs `unsafe`, and this crate's `unsafe` budget is one block, in
797/// [`OwnedWriter`], spent on the lifetime extension `docs/decisions/0017`
798/// authorised — an earlier revision of this sentence said the crate was
799/// `#![forbid(unsafe_code)]` and could not have a `ManuallyDrop` at any price,
800/// which stopped being true when that record landed. **Do not reorder these
801/// fields.**
802///
803/// # Storing one
804///
805/// You cannot: the lifetime is the point. [`OwnedWriter`] is the shape for a
806/// claim that outlives its scope (`docs/API.md` §2.1).
807pub struct EdgeWriter<'a> {
808    publisher: Publisher<'a>,
809    /// The fork generation this writer was claimed in.
810    ///
811    /// `Copy`, so it takes no part in the drop order above; it is declared here
812    /// only to keep the two drop-ordered fields adjacent.
813    #[cfg(all(feature = "shm", target_os = "linux"))]
814    fork_gen: Option<u64>,
815    /// Held purely for its `Drop`, hence the underscore — nothing reads it, and
816    /// the observable effect is releasing the byte when this value dies.
817    #[cfg(all(feature = "shm", target_os = "linux"))]
818    _lease: Option<ClaimLease>,
819}
820
821impl EdgeWriter<'_> {
822    /// Whether this writer belongs to the pre-`fork` process. One relaxed load.
823    #[cfg(all(feature = "shm", target_os = "linux"))]
824    fn detached(&self) -> bool {
825        self.fork_gen
826            .is_some_and(|g| g != tf_tree_ipc::fork::generation())
827    }
828
829    /// Publish `iso` at `stamp` on the claimed edge.
830    ///
831    /// # Errors
832    ///
833    /// [`PushError::NonMonotonicStamp`] if `stamp` predates the edge's newest;
834    /// [`PushError::ClaimRevoked`] if a reaper judged this writer dead and took
835    /// the edge away (`docs/PHASE2.md` §1, A4);
836    /// [`PushError::ChildDetached`] if this writer was claimed before a `fork()`
837    /// and is being used in the child.
838    ///
839    /// # Why this shadows the `Deref` target
840    ///
841    /// An inherent method wins over a `Deref` one, so `writer.push(..)` lands
842    /// here and gets the fork check. Reaching the inner [`Publisher`] explicitly
843    /// — `(&*writer).push(..)` — skips it, and after a `fork` that is a write
844    /// through a dangling reference into an unmapped page. The `Deref` is kept
845    /// because it is what makes every pre-existing caller compile unchanged, but
846    /// **do not route `push` around it.**
847    ///
848    /// # Cost, measured
849    ///
850    /// `+0.195 ns` on a shared-arena push — 9.041 ns against 8.846 ns for the
851    /// same benchmark with the branch forced not-taken (`benches/push.rs`,
852    /// `--features shm`). One relaxed load of a process-local static plus a
853    /// predictable branch. A heap tree carries `None` and pays only the
854    /// discriminant test, so the single-process path is unchanged (8.71 ns).
855    ///
856    /// That is the price of a `fork` child not writing through a dangling
857    /// pointer into an unmapped page, which is not a trade this hot path gets
858    /// to decline.
859    pub fn push(&self, stamp: i64, iso: &Iso3) -> Result<(), PushError> {
860        #[cfg(all(feature = "shm", target_os = "linux"))]
861        if self.detached() {
862            return Err(PushError::ChildDetached);
863        }
864        self.publisher.push(stamp, iso)
865    }
866}
867
868impl Drop for EdgeWriter<'_> {
869    fn drop(&mut self) {
870        // `Publisher`'s own `Drop` releases the claim with a `compare_exchange`
871        // *into the arena*. In a `fork` child that arena is a hole in the
872        // address space, so the destructor faults — and it does so whether or
873        // not the child ever called anything, which is what makes it the most
874        // dangerous of the four inherited destructors.
875        //
876        // Found by `a_forked_child_runs_its_destructors_without_touching_the_parent`,
877        // which failed with `child=signalled 11` while every API-level check in
878        // the same child passed. Guarding `Tree::drop` is not sufficient: a
879        // `Drop` impl's early return does not stop the struct's *fields* from
880        // being dropped afterwards, so every owned resource has to stand itself
881        // down.
882        #[cfg(all(feature = "shm", target_os = "linux"))]
883        if self.detached() {
884            self.publisher.abandon();
885        }
886    }
887}

889impl<'a> core::ops::Deref for EdgeWriter<'a> {
890    type Target = Publisher<'a>;
891
892    fn deref(&self) -> &Publisher<'a> {
893        &self.publisher
894    }
895}

897/// An [`EdgeWriter`] that owns its tree — the claim shape for a writer that is
898/// **stored** rather than scoped (`docs/decisions/0017`, `docs/API.md` §2.1).
899///
900/// # Which one to use
901///
902/// [`Tree::claim`] is the default and stays it. Where the claim's scope is
903/// lexical the borrow checker enforces the claim's lifetime for free, and that
904/// is worth more than the `Arc` this type costs. Reach for [`Tree::claim_owned`]
905/// only when the writer outlives the scope that made it: a node that publishes
906/// for the life of the process, or a binding whose handle type cannot carry a
907/// lifetime at all. Two ways to claim an edge now exist, and if this one becomes
908/// the copy-pasted default the compile-time claim-scope check is lost for
909/// everybody.
910///
911/// # It carries no lifetime, which is the entire point
912///
913/// ```
914/// use std::sync::Arc;
915/// use tf_tree::{Capacity, EdgeCfg, Iso3, OwnedWriter, TreeBuilder};
916///
917/// // No lifetime parameter on the user's type. `EdgeWriter<'a>` cannot do this.
918/// struct OdomPublisher {
919///     writer: OwnedWriter,
920/// }
921///
922/// let tree = Arc::new(
923///     TreeBuilder::new()
924///         .dynamic_edge("odom", "base", EdgeCfg::new(Capacity::slots(64)))
925///         .build()
926///         .expect("layout"),
927/// );
928/// let base = tree.frame("base").unwrap();
929/// let odom = tree.frame("odom").unwrap();
930/// let node = OdomPublisher {
931///     writer: tree.claim_owned(base, odom).expect("claim"),
932/// };
933///
934/// // The caller's handle goes away; the writer keeps the arena alive by itself.
935/// drop(tree);
936/// node.writer.push(1_000, &Iso3::IDENTITY).expect("push");
937/// ```
938///
939/// # Auto traits
940///
941/// `Send + !Sync`, exactly as [`Publisher`] is: single-writer-per-edge stays a
942/// *type-level* property (`docs/PROJECT.md` §5 D7), not a convention this type
943/// relaxes. Both are inherited from the [`EdgeWriter`] field — there is no
944/// `unsafe impl Send` here and there must never be one, because an `unsafe impl`
945/// would still compile after somebody replaced the field with something that had
946/// no business crossing a thread.
947///
948/// `OwnedWriter` is `Send`:
949/// ```
950/// fn assert_send<T: Send>() {}
951/// assert_send::<tf_tree::OwnedWriter>();
952/// ```
953///
954/// but deliberately **not** `Sync` (this must fail to compile):
955/// ```compile_fail,E0277
956/// fn assert_sync<T: Sync>() {}
957/// assert_sync::<tf_tree::OwnedWriter>();
958/// ```
959///
960/// The error code is pinned on purpose. A bare `compile_fail` passes when the
961/// snippet fails to compile for *any* reason — including `OwnedWriter` being
962/// renamed, moved or un-exported — so it would keep reporting success while
963/// testing nothing. `E0277` is the unsatisfied-trait-bound failure that is
964/// actually under test.
965///
966/// **rustdoc enforces the code on nightly only** — measured: mutating it to
967/// `E0599` fails `cargo +nightly test --doc -p tf_tree` with *"Some expected
968/// error codes were not found: \["E0599"\]"* and still reports `ok` on stable.
969/// So `just test-doc` (stable, `--workspace`) is **not** the gate for this line;
970/// `just test-doc-error-codes` is — one nightly command, run by CI's `miri` job,
971/// which exists so this pin is a check rather than something that reads like
972/// one.
973///
974/// The *renamed-or-unexported* half is covered on stable regardless, by
975/// `assert_send::<tf_tree::OwnedWriter>()` in
976/// `crates/tf_tree/tests/owned_writer.rs`, which stops compiling if the path
977/// moves. The three together leave no way for this to pass while testing
978/// nothing.
979///
980/// # Every guard is reproduced, and not by copying one
981///
982/// `EdgeWriter::drop` does three things a hand-rolled owned writer has to do
983/// too: [`Publisher::abandon`] in a `fork` child, the `ClaimLease` release, and
984/// the fork-generation compare that decides both. This type gets all three by
985/// **containing the `EdgeWriter` whole** rather than by restating them, which is
986/// what makes the count unable to drift. The defect `0017` exists to remove was
987/// exactly a restatement that dropped two of the three: a
988/// `transmute::<EdgeWriter, Publisher>` in `tf_tree_py` that kept the first
989/// field, leaked the lease for the life of every Python publisher — so no reaper
990/// would ever collect the edge either — and bypassed the fork guard.
991///
992/// # Drop order is load-bearing, for a second reason
993///
994/// The fields are declared **writer first, `tree` second**, and Rust drops them
995/// in declaration order. The writer releases the claim by writing *into the
996/// arena*; the `Arc` is what keeps that arena mapped. Reversing them is a
997/// use-after-free on the last handle rather than the merely-wrong ordering
998/// [`EdgeWriter`]'s own field order guards against. **Do not reorder these
999/// fields.**
1000///
1001/// # Why the writer is behind a `Box`
1002///
1003/// Not for size, and not for the `Arc`: **an inline `EdgeWriter<'static>` here
1004/// is Undefined Behavior on drop**, under Stacked Borrows *and* Tree Borrows.
1005/// `just miri` reports it, the rest of the suite does not, and the box is what
1006/// `just miri` goes green on.
1007///
1008/// The mechanism, because it is not obvious. An `EdgeWriter` holds `&`
1009/// references into the arena. When a value is passed to a function **by
1010/// value**, the reference-typed fields inside it are retagged with a *strong
1011/// protector* for the whole call — that is what makes a reference argument
1012/// dereferenceable for the duration of a call. Both `drop(writer)` and
1013/// [`Self::release`] are exactly that: a by-value pass whose callee then drops
1014/// the last `Arc`, and freeing the arena while a strong protector points into
1015/// it is UB. It is not hypothetical model-lawyering — Miri's default
1016/// (`-Zmiri-retag-fields=all`) reports
1017/// *"deallocating while item \[SharedReadOnly …\] is strongly protected"*, and
1018/// `-Zmiri-tree-borrows` reports the Tree Borrows equivalent.
1019///
1020/// A `Box` field is *weakly* protected — deallocating through it is exactly
1021/// what a `Box` is for — and retagging does not reach through a pointer into
1022/// the boxed value, so the arena references are never protected across the
1023/// `Arc`'s release. Dropping through the box is then an ordinary in-place drop,
1024/// which was already sound: an `OwnedWriter` that falls out of scope, or that
1025/// lives in somebody's struct, never tripped this at all. Only the by-value
1026/// spellings did — which are the two this type documents as the way to release.
1027///
1028/// **The cost is one pointer chase in [`Self::push`], and it buys soundness on
1029/// the shape this type exists to provide.** [`EdgeWriter::push`],
1030/// [`Publisher::push`] and every scoped claim are untouched: this is a new path
1031/// that pays it, not an existing one that regressed. The alternative that would
1032/// not pay it is `Publisher` holding raw pointers instead of `&` — a change to
1033/// the `no_std` core's hot struct, which is a decision record, not a tidy-up.
1034pub struct OwnedWriter {
1035    /// The claim, with its borrow of the tree below extended to `'static`.
1036    ///
1037    /// Declared first so it drops first — see the type's doc comment.
1038    ///
1039    /// **Boxed for soundness, not for size, and it must stay boxed.** See the
1040    /// type's *Why the writer is behind a `Box`* section: with the `EdgeWriter`
1041    /// inline, `drop(writer)` and [`Self::release`] are both Undefined Behavior
1042    /// under Stacked *and* Tree Borrows, and `just miri` says so.
1043    writer: Box<EdgeWriter<'static>>,
1044    /// The strong reference that makes the field above's `'static` true.
1045    ///
1046    /// Never read, hence the `allow` — but **do not delete it**, and do not
1047    /// replace it with a `PhantomData`. It is the entire safety argument for the
1048    /// `'static` above; removing it leaves a writer pointing into an arena
1049    /// nothing is keeping alive, which is a use-after-free that compiles.
1050    ///
1051    /// Spelled without a leading underscore on purpose: the underscore
1052    /// convention in this file means "held only for its `Drop`" (see
1053    /// `EdgeWriter::_lease`), and this is held for its *refcount* — it has to be
1054    /// alive for the writer's whole life, not merely torn down in a particular
1055    /// order at the end of it.
1056    #[allow(dead_code)]
1057    tree: Arc<Tree>,
1058}

1060impl OwnedWriter {
1061    /// The edge this writer owns.
1062    ///
1063    /// The same accessor [`Publisher::edge`] gives a scoped writer through
1064    /// [`EdgeWriter`]'s `Deref`, forwarded by hand because `OwnedWriter` has no
1065    /// `Deref`: one to [`Publisher`] would also expose [`Publisher::push`],
1066    /// which is the copy without the fork check (see [`Self::push`]).
1067    ///
1068    /// It is not decoration. An `EdgeId` is what names a claim to everything
1069    /// outside the arena's frame table — the lock file's byte, a counter row, a
1070    /// diagnostic — and a caller that cannot ask the writer has to re-derive it
1071    /// from a seqlock topology read that can fail, and then has no cross-check
1072    /// left that the two agree.
1073    #[inline]
1074    #[must_use]
1075    pub fn edge(&self) -> EdgeId {
1076        self.writer.edge()
1077    }
1078
1079    /// Publish `iso` at `stamp` on the claimed edge.
1080    ///
1081    /// # Errors
1082    ///
1083    /// [`PushError::NonMonotonicStamp`] if `stamp` predates the edge's newest;

1136/// Holds an edge's claim byte for as long as this value lives.
1137#[cfg(all(feature = "shm", target_os = "linux"))]
1138pub(crate) struct ClaimLease {
1139    lock: std::sync::Arc<tf_tree_ipc::LockFile>,
1140    edge: u32,
1141    /// The fork generation this lease was taken in.
1142    ///
1143    /// An OFD lock belongs to the **open file description**, which a `fork`
1144    /// child inherits — so an unlock issued by the child releases the *parent's*
1145    /// byte. Dropping an inherited `EdgeWriter` in a child would therefore hand
1146    /// the parent's live edge to the next reaper, from another process, with
1147    /// nothing in the parent's logs to show for it.

1149}

1151#[cfg(all(feature = "shm", target_os = "linux"))]
1152impl Drop for ClaimLease {
1153    fn drop(&mut self) {
1154        // Never unlock from a `fork` child: the byte is the parent's (see
1155        // `fork_gen`). Leaking it here leaks nothing — the description stays
1156        // open in the parent, which still owns and will still release it.
1157        if self.fork_gen != tf_tree_ipc::fork::generation() {
1158            return;
1159        }
1160        // Best effort: if the unlock fails the process is in no state to react,
1161        // and the kernel releases the byte at exit regardless — which is the
1162        // property the lease exists for.
1163        let _ = self.lock.release_claim(self.edge);
1164    }

1176/// publishing samples and looking up transforms. Build one with [`TreeBuilder`].

1178/// `Send + Sync`: the arena's interior mutation is all atomic, the single runtime
1179/// topology mutation ([`Self::reparent`]) is serialized by the in-arena topology

1305    /// opened before a `fork()` and this is the child.
1306    ///
1307    /// One relaxed load of a process-local counter; see `tf_tree_ipc::fork`
1308    /// for why it is not `getpid()`.
1309    ///
1310    /// A detached tree is not repairable. Open a new one in the child, or
1311    /// `exec`.
1312    #[must_use]
1313    pub fn detached(&self) -> bool {
1314        #[cfg(all(feature = "shm", target_os = "linux"))]
1315        {
1316            self.fork_gen
1317                .is_some_and(|g| g != tf_tree_ipc::fork::generation())

1319        #[cfg(not(all(feature = "shm", target_os = "linux")))]

1325    /// The crate-internal view, and **the one this crate's own modules use**.
1326    ///
1327    /// [`Tree::arena_view`] is the public spelling of it and is gated on the
1328    /// `unstable` feature (`docs/API.md` §2.6); `frozen.rs` and `open.rs` are
1329    /// inside the facade and must not reach a public surface to do their work,
1330    /// or the feature would be load-bearing for a default build.
1331    pub(crate) fn view(&self) -> ArenaView<'_> {
1332        // The detached case first, and unconditionally: every accessor below
1333        // funnels through here, so this is the one place that has to be right
1334        // for a read of the vanished mapping to be impossible rather than
1335        // merely unlikely.
1336        #[cfg(all(feature = "shm", target_os = "linux"))]
1337        if self.detached() {
1338            return ArenaView::new(poison_arena());
1339        }
1340        // Both builders are load-bearing for A8, and neither is optional:
1341        //
1342        // * `as_participant` — a rescuer publishes *itself* into `claiming`, so
1343        //   an anonymous view can wait on a stalled interner but may never take
1344        //   the entry over. Without this, A8's recovery is inert.
1345        // * `with_liveness` — the default is "believed alive", the right
1346        //   fail-safe but one that never fires. This is what makes a dead
1347        //   claimant's entry actually recoverable.
1348        ArenaView::new(self.arena.as_dyn())
1349            .as_participant(self.participant)
1350            .with_liveness(&*self.liveness)
1351            // Third builder, and as load-bearing as the other two: without it
1352            // the diagnostic counters (`docs/PHASE5.md` §5) write through a
1353            // read-only mapping and the process dies with SIGSEGV.
1354            .writable(self.is_writable())
1355    }

1357    /// Resolve a frame name to its stable id.
1358    ///
1359    /// A name declared at build time resolves to its existing id without
1360    /// consuming a slot. A name that was never declared is interned on demand,
1361    /// which needs a free frame slot (see [`TreeBuilder::frame_headroom`]).
1362    ///
1363    /// # Errors
1364    ///
1365    /// **[`FrameError::ReadOnly`] if this tree is a read-only attachment and
1366    /// `name` is not already interned** — which is the most common failure on
1367    /// the default attach (`Open::new` is read-only, D18), and the one
1368    /// this section used not to mention at all. It is not a permissions
1369    /// complaint about a name that exists: it means *this name is not declared
1370    /// and I cannot declare it*. A consumer racing its publisher wants
1371    /// [`Tree::await_frames`]; a consumer that will never see the name declared
1372    /// wants the creator to declare it, or `frame_headroom` and a writable
1373    /// attach.
1374    ///
1375    /// Also [`FrameError::CapacityExceeded`] if the frame table is full,
1376    /// [`FrameError::FrameHashCollision`] if a name hash collides,
1377    /// [`FrameError::InternContended`] if another interner holds the name's
1378    /// slot and cannot be judged, and [`FrameError::ChildDetached`] on a tree
1379    /// inherited across a `fork()`.
1380    pub fn frame(&self, name: &str) -> Result<FrameId, FrameError> {
1381        // Explicitly, ahead of `view()`: the poison arena is a *writable* heap
1382        // arena, so interning into it would succeed and hand back a `FrameId`
1383        // that names nothing. A wrong answer is worse than an error.
1384        if self.detached() {
1385            return Err(FrameError::ChildDetached);
1386        }
1387        if !self.arena.is_writable() {
1388            // Interning a *new* name publishes into the hash table with a
1389            // `compare_exchange`; through a `PROT_READ` mapping that is a
1390            // `SIGSEGV`, not an error. Resolving an existing name is a pure
1391            // read, so a read-only participant can still do that — which is
1392            // every name the creator declared.
1393            return self.view().find_frame(name)?.ok_or(FrameError::ReadOnly);
1394        }
1395        self.view().intern(name)
1396    }

1398    /// Every interned frame's name, in [`FrameId`] order.
1399    ///
1400    /// The stable answer to "what is in this tree", and the plural of
1401    /// [`Tree::frame`]. It is on the *stable* surface deliberately: an embedder
1402    /// must not have to enable the `unstable` feature to ask what their own tree
1403    /// contains, which is what gating `Tree::arena_view` would otherwise have
1404    /// forced (`docs/API.md` §2.6, §7 check 1). Python has had `tree.frames()`
1405    /// since §3.2 and this is its mirror.
1406    ///
1407    /// # Names only
1408    ///
1409    /// No rate, no jitter, no sample count. That is `docs/PHASE5.md` §4.2's
1410    /// `ds.edges()` and it stays held back until §3's counting pass exists —
1411    /// the same line the Python surface draws.
1412    ///
1413    /// # The snapshot is a snapshot
1414    ///
1415    /// On a live shared arena another process may intern a frame while this
1416    /// walk runs, so the list is what was true at some instant inside the call,
1417    /// exactly as [`crate::Plan::latest`] already is. Frames are append-only, so
1418    /// what it *does* promise is that nothing in it will be removed or renamed;
1419    /// a later call can only be longer.
1420    ///
1421    /// A slot whose id has been counted but whose record is not yet written is
1422    /// skipped rather than reported with an empty name — see the walk's own
1423    /// comments for what that filter is and, more importantly, what it is not.
1424    ///
1425    /// `frame_count` over-counts by one when a frame is abandoned mid-intern
1426    /// (`tf_tree_core::frame`'s `finish`: the record "stays written but
1427    /// unreferenced"), and that abandoned record carries a real name and a
1428    /// non-zero hash, so it lands here at a second id. `len()` is therefore an
1429    /// upper bound on the tree's frames, not the frame count.
1430    ///
1431    /// # Errors
1432    ///
1433    /// [`LookupError::ChildDetached`] on a tree inherited across a `fork()`.
1434    /// Such a tree reads a one-frame poison arena, so answering would hand back
1435    /// a plausible-looking short list instead of naming the fork.
1436    pub fn frames(&self) -> Result<Vec<String>, LookupError> {
1437        if self.detached() {
1438            return Err(LookupError::ChildDetached);
1439        }
1440        let view = self.view();
1441        // **`Relaxed`, and that is the justified ordering rather than the cheap
1442        // one.** `tf_tree_core::frame`'s `finish` does `frame_count.fetch_add`
1443        // *first*, then `write_record`, then the Release publish into the intern
1444        // table. An `Acquire` load here would therefore order this thread
1445        // against everything the interner did *before* it took its id — and
1446        // against nothing it did after, which is precisely the record about to
1447        // be read. Acquire would read like a guarantee and buy none.
1448        //
1449        // What no ordering available here buys is a race-free read.
1450        // `FrameRecord`'s fields are plain integers and its publication edge is
1451        // keyed by *name*, through the intern table; an enumeration keyed by id
1452        // has no edge to acquire. The `name_hash` filter below is a filter on
1453        // the value read, not the missing edge, and is not claimed to be one.
1454        let count = view.header().frame_count.load(Ordering::Relaxed);
1455        let mut out = Vec::with_capacity(count as usize);
1456        for raw in 1..=count {
1457            // Three checks — the strictest set any copy of this walk applied
1458            // before this method existed, which is the point of the method:
1459            //
1460            //  1. `FrameId::new` rejects 0, the root sentinel.
1461            //  2. `raw <= frame_count` — *this loop's bound*, and load-bearing
1462            //     rather than incidental: `frame_record` bounds against
1463            //     `max_frames`, which is `frame_count + 1 + frame_headroom`, so
1464            //     walking further hands back zeroed headroom slots as frames.
1465            //  3. `name_hash != 0`, below.
1466            let Some(id) = FrameId::new(raw) else {
1467                continue;
1468            };
1469            let Some(rec) = view.frame_record(id) else {
1470                continue;
1471            };
1472            // **The count is bumped before the record is written**, so an
1473            // interner in another process can be counted here one instant
1474            // before its name exists and the slot still reads as zeros. A
1475            // written record's `name_hash` is BLAKE3 of the name — non-zero
1476            // even for `""` — so a zero hash means "not written yet". Skipping
1477            // it lists that frame one call later; taking it prints a frame with
1478            // an empty name, which reads as our bug rather than as a race lost
1479            // by a microsecond.
1480            if rec.name_hash == 0 {
1481                continue;
1482            }
1483            out.push(stored_name(&rec.name, rec.name_len));
1484        }
1485        Ok(out)
1486    }

1488    /// Wait until every name in `names` is interned, and return their ids.
1489    ///
1490    /// **The second of `docs/decisions/0019` §2b's two waits.**
1491    /// `Open::await_open` waits for the *arena* to exist; this waits
1492    /// for *names* to be interned into an arena that already does. They are two
1493    /// different absences, and a consumer that started before its publisher
1494    /// meets both.
1495    ///
1496    /// Array in, array out, and **no allocation**: `N` is a const generic, and
1497    /// ids found on an early iteration are memoized rather than re-probed —
1498    /// which is legal because frames are append-only (D10), so a name once found
1499    /// cannot become unfound. That memoization is a *cost* property only:
1500    /// `find_frame` is idempotent, so dropping it would return the same ids,
1501    /// just after re-hashing every already-resolved name on every iteration. No
1502    /// assertion anywhere observes it, and `tests/rendezvous.rs` says so rather
1503    /// than claiming a guard it does not have.
1504    ///
1505    /// # The predicate is `find_frame`, and two handles are refused outright
1506    ///
1507    /// The wait polls the arena's intern table directly, never [`Tree::frame`],
1508    /// which is the wrong predicate in *both* modes for opposite reasons: on a
1509    /// read-only arena it answers [`FrameError::ReadOnly`] for an absent name —
1510    /// so the wait would never resolve — and on a writable one it **interns and
1511    /// succeeds immediately**. The second is the dangerous one: it is a
1512    /// confident wrong answer, an id for a name nobody declared.
1513    ///
1514    /// So a writable tree gets [`AwaitError::WritableTree`] rather than a
1515    /// silently-chosen meaning, before any sleep. A publisher already has
1516    /// [`Tree::frame`], which on its tree cannot fail for absence. A frozen
1517    /// `.tft` gets [`AwaitError::FrozenTree`] for the sibling reason: it has no
1518    /// writers, so the poll is futile by construction.
1519    ///
1520    /// **Which gate pins which half**, because they are not the same gate. The
1521    /// `WritableTree` refusal is `tests/await_frames.rs` under plain
1522    /// `just test`; `FrozenTree` is `tests/frozen.rs` under `just shm-check`;
1523    /// and the choice of `find_frame` over [`Tree::frame`] can only be observed
1524    /// on a *read-only* handle, which a default build cannot construct at all —
1525    /// it is pinned by `a_consumer_waits_for_a_frame_interned_after_the_arena_exists`
1526    /// in `tests/rendezvous.rs`, under `just shm-rendezvous`, and nowhere else.
1527    ///
1528    /// # Granularity
1529    ///
1530    /// A bounded poll — `MIN_BACKOFF` 200 µs doubling to `MAX_BACKOFF` 4 ms,
1531    /// this crate's pair, shared with `Open::await_open` — not a notification.
1532    /// `docs/decisions/0018` records
1533    /// why there is no arena-resident primitive to wake on (a `PROT_READ`
1534    /// consumer cannot register on one without giving up D18's boundary), and
1535    /// the argument applies here with more force because topology settles once,
1536    /// at startup. This therefore returns *later* than the name appeared, by up
1537    /// to one backoff interval plus scheduler granularity.
1538    ///
1539    /// # Errors
1540    ///
1541    /// [`AwaitError::WritableTree`] immediately on a writable tree;
1542    /// [`AwaitError::FrozenTree`] immediately on a frozen `.tft`;
1543    /// [`AwaitError::ChildDetached`] on a tree inherited across a `fork()`;
1544    /// [`AwaitError::Frame`] if a name resolves to a hash collision or a
1545    /// contended interner; [`AwaitError::Timeout`] carrying the hash of the
1546    /// **first** name still missing when the budget ran out — first in `names`
1547    /// order, not first probed, so a request whose leading names resolved names
1548    /// the earliest one that did not.
1549    ///
1550    /// # Examples
1551    ///
1552    /// The refusal, which is the part of the contract a caller most needs to
1553    /// know and the only part reachable without a shared arena:
1554    ///
1555    /// ```
1556    /// use std::time::Duration;
1557    /// use tf_tree::{AwaitError, Iso3, TreeBuilder};
1558    ///
1559    /// let tree = TreeBuilder::new()
1560    ///     .static_edge("map", "odom", &Iso3::IDENTITY)
1561    ///     .build()
1562    ///     .expect("layout");
1563    ///
1564    /// // A heap tree is writable, so `Tree::frame` would intern "no_such_frame"
1565    /// // on demand and hand back an id for a frame nobody declared. This says so
1566    /// // instead — and says it in microseconds, not after the five seconds.
1567    /// let started = std::time::Instant::now();
1568    /// assert_eq!(
1569    ///     tree.await_frames(["map", "no_such_frame"], Duration::from_secs(5)),
1570    ///     Err(AwaitError::WritableTree),
1571    /// );
1572    /// assert!(started.elapsed() < Duration::from_millis(100));
1573    ///
1574    /// // On that tree the right call is `Tree::frame`, which cannot fail for
1575    /// // absence.
1576    /// assert!(tree.frame("map").is_ok());
1577    /// ```
1578    ///
1579    /// And the consumer this method exists for — `docs/decisions/0019` §2b's
1580    /// startup sequence. **`text`, not `rust`, and that is the record's own
1581    /// deliberate choice**: the three calls yield `OpenError`, `AwaitError` and
1582    /// [`LookupError`], and `LookupError` implements neither `Display` nor
1583    /// `Error`, so no single `?`-chain unifies them — not even into
1584    /// `Box<dyn Error>`. It also needs a live arena and `--features shm`.
1585    ///
1586    /// ```text
1587    /// // Two waits, because they are two different absences.
1588    /// let tree = tf_tree::Open::new()
1589    ///     .mode(AttachMode::ReadOnly)                      // implies CreatePolicy::Never
1590    ///     .await_open(Duration::from_secs(5))?;            // wait for the arena
1591    /// let [target, source] =
1592    ///     tree.await_frames(["map", "base_link"], Duration::from_secs(5))?;
1593    /// let plan = tree.plan(target, source)?;
1594    /// ```
1595    pub fn await_frames<const N: usize>(
1596        &self,
1597        names: [&str; N],
1598        timeout: Duration,
1599    ) -> Result<[FrameId; N], AwaitError> {
1600        // Before any sleep, and before any arena read: this is a property of
1601        // the handle, and burning a five-second budget to report it would be
1602        // the worst of both answers.
1603        if self.is_writable() {
1604            return Err(AwaitError::WritableTree);
1605        }
1606        // The other statically-futile handle. A frozen arena is read-only *and*
1607        // writer-free (`docs/PHASE5.md` §2.4), so the poll below would run the
1608        // caller's whole budget and report a timeout for something that was
1609        // never coming. Distinct condition, distinct answer.
1610        if self.arena.is_frozen() {
1611            return Err(AwaitError::FrozenTree);
1612        }
1613        let start = std::time::Instant::now();
1614        let mut found: [Option<FrameId>; N] = [None; N];
1615        let mut backoff = MIN_BACKOFF;
1616        loop {
1617            // **Per iteration, and before `view()`.** `view()` answers a fork
1618            // victim with the poison arena, whose `find_frame` returns
1619            // `Ok(None)` for every name — so without this a detached tree waits
1620            // out the whole budget and then reports a timeout for something
1621            // that is not one.
1622            if self.detached() {
1623                return Err(AwaitError::ChildDetached);
1624            }
1625            let view = self.view();
1626            for (slot, name) in found.iter_mut().zip(names.iter()) {
1627                if slot.is_some() {
1628                    // Memoized. Frames are append-only (D10), so a name once
1629                    // found cannot become unfound and re-probing it would only
1630                    // pay for the hash again.
1631                    continue;
1632                }
1633                match view.find_frame(name) {
1634                    Ok(id) => *slot = id,
1635                    // Terminal — see `AwaitError::Frame`.
1636                    Err(e) => return Err(AwaitError::Frame(e)),
1637                }
1638            }
1639            if let Some(ids) = all_interned(&found) {
1640                return Ok(ids);
1641            }
1642            // Deadline **after** the work and **before** the sleep, so a name
1643            // interned during the last iteration is reported rather than napped
1644            // past. `saturating_*` throughout: `Duration` subtraction panics.
1645            if start.elapsed() >= timeout {
1646                let hash = names
1647                    .iter()
1648                    .zip(found.iter())
1649                    .find(|(_, slot)| slot.is_none())
1650                    // Unreachable: `all_interned` returned `None`, so some slot
1651                    // is empty. `map_or` rather than `unwrap` because this crate
1652                    // denies both, and a wrong hash is a worse answer than a
1653                    // panic only if somebody matches on it, which R5 forbids.
1654                    .map_or(0, |(name, _)| blake3_64(name));
1655                return Err(AwaitError::Timeout { hash });
1656            }
1657            // Never sleep past the caller's deadline.
1658            let left = timeout.saturating_sub(start.elapsed());
1659            std::thread::sleep(core::cmp::min(backoff, left));
1660            backoff = core::cmp::min(backoff * 2, MAX_BACKOFF);
1661        }
1662    }

1664    /// Every declared edge as a `(parent, child)` name pair, in [`EdgeId`]
1665    /// order.
1666    ///
1667    /// The stable mirror of Python's `tree.edges()` (`docs/API.md` §3.2), and
1668    /// on the stable surface for [`Tree::frames`]'s reason.
1669    ///
1670    /// `(parent, child)` is [`TreeBuilder::dynamic_edge`]'s argument order, so
1671    /// the list reads back the way it was written — but it rebuilds the *graph*
1672    /// only: the pair does not report the edge's kind, and telling a static edge
1673    /// from a dynamic one is `tf_tree::unstable::EdgeKind`'s job, which is
1674    /// arena-shaped and therefore unstable (`docs/API.md` §2.6).
1675    ///
1676    /// The pair is read out of the [`EdgeId`]'s own record, which is the
1677    /// *declared* topology. [`Tree::reparent`] moves a child under a new parent
1678    /// without rewriting that record, so on a reparented tree this names the
1679    /// edge's declaration and the live topology block names its current parent.
1680    /// They can disagree, and every other listing in this workspace makes the
1681    /// same choice: one answer that is wrong after a reparent beats two answers
1682    /// that disagree with each other.
1683    ///
1684    /// # Names only
1685    ///
1686    /// See [`Tree::frames`] — the statistics half is `docs/PHASE5.md` §4.2's and
1687    /// is held back on every surface, not just this one.
1688    ///
1689    /// # Errors
1690    ///
1691    /// [`LookupError::ChildDetached`] on a tree inherited across a `fork()`.
1692    /// The poison arena such a tree reads has zero edges, so without this the
1693    /// answer is a silent empty list.
1694    pub fn edges(&self) -> Result<Vec<(String, String)>, LookupError> {
1695        if self.detached() {
1696            return Err(LookupError::ChildDetached);
1697        }
1698        let view = self.view();
1699        // `edge_count` is stored as (declared edges + 1 sentinel), so the real
1700        // ids are `1..edge_count` — `tf_tree_core::EdgeId`'s own doc comment,
1701        // and the off-by-one that cost `tf_tree_c::unstable` a test.
1702        //
1703        // `Relaxed` needs no argument beyond `frames`': unlike `frame_count`
1704        // there is no window at all. The edge table is sized and filled by
1705        // `TreeBuilder` and `edge_count` is stored exactly once, before the
1706        // arena is ever shared; nothing declares an edge at runtime.
1707        let count = view.header().edge_count.load(Ordering::Relaxed);
1708        let mut out = Vec::with_capacity(count.saturating_sub(1) as usize);
1709        for raw in 1..=count {
1710            // One observation of the record, not two: re-reading `view.edge`
1711            // for the child could name a parent and a child that never belonged
1712            // to the same edge.
1713            let Some(rec) = view.edge(EdgeId(raw)) else {
1714                continue;
1715            };
1716            // `None` from either endpoint means a slot whose record is still
1717            // zeros, because a zeroed record names frame 0 and `FrameId::new(0)`
1718            // declines. **That is what keeps the sentinel and any headroom slot
1719            // out of this list**, not the loop bound, so the tempting "never
1720            // drop an entry" fallback to a `<root>` placeholder would put
1721            // `("", "")`-shaped noise in the answer instead.
1722            let name = |f: u32| -> Option<String> {
1723                let r = view.frame_record(FrameId::new(f)?)?;
1724                Some(stored_name(&r.name, r.name_len))
1725            };
1726            let (Some(parent), Some(child)) = (name(rec.parent), name(rec.child)) else {
1727                continue;
1728            };
1729            out.push((parent, child));
1730        }
1731        Ok(out)
1732    }

1734    /// Re-parent an existing `child` frame under `new_parent`, reusing the child's
1735    /// already-declared edge (no new capacity is allocated). This is the only
1736    /// runtime topology mutation; it bumps the topology generation, invalidating
1737    /// compiled [`crate::Plan`]s so they recompile against the new shape.
1738    ///
1739    /// # Serialization (`docs/PHASE2.md` §1, A2)
1740    ///
1741    /// Two locks, doing two different jobs:
1742    ///
1743    /// * `self.decl`, a plain `Mutex`, keeps *this* process's threads out of
1744    ///   each other's way. It serializes nothing across a process boundary and
1745    ///   never did; it is kept because it is free and stops two threads of one
1746    ///   process burning the arena lock's spin budget against each other.
1747    /// * The **in-arena** [`TopoLockView`] is the real one. Its word lives in
1748    ///   the header, so every participant that mapped the segment contends on
1749    ///   the same bytes, and it is stealable from a participant that died
1750    ///   holding it — which is why this is no longer refused on a shared arena.
1751    ///
1752    /// # Errors
1753    ///
1754    /// [`ReparentError::NoEdge`] if `child` has no incoming edge to reuse,
1755    /// [`ReparentError::Topology`] if the move would create a cycle or references
1756    /// an out-of-range frame, or [`ReparentError::LockContended`] if a live peer
1757    /// holds the topology lock (retry).
1758    pub fn reparent(&self, child: FrameId, new_parent: FrameId) -> Result<(), ReparentError> {
1759        if self.detached() {
1760            return Err(ReparentError::ChildDetached);
1761        }
1762        if !self.arena.is_writable() {
1763            return Err(ReparentError::ReadOnly);
1764        }
1765        let _local = self.decl.lock().unwrap_or_else(|e| e.into_inner());
1766        let view = self.view();
1767        let header = view.header();
1768        let lock = TopoLockView::new(&header.topo_lock.owner, &header.topo_lock.acquired_at_nanos);
1769        let participants = view.participants();
1770        let arena_boot = header.boot_id;
1771        let is_alive = move |slot: u32| participant_is_alive(&participants, slot, &arena_boot);
1772        let _topo = lock.acquire(self.participant, now_nanos(), &is_alive)?;
1773
1774        let (_p, _depth, edge, _gen) =
1775            view.topology()
1776                .read_frame(child)
1777                .ok_or(ReparentError::Topology(TopologyError::UnknownFrame {
1778                    frame: child.get(),
1779                }))?;
1780        if edge == 0 {
1781            return Err(ReparentError::NoEdge { child });
1782        }
1783        view.topology().set_parent(child, new_parent.get(), edge)?;
1784        Ok(())
1785    }

1787    /// Claim exclusive write access to the dynamic edge whose child is `child`
1788    /// (and whose parent must be `parent`). Returns a [`Publisher`]; dropping it
1789    /// releases the claim.
1790    ///
1791    /// # Errors
1792    ///
1793    /// [`ClaimApiError`] if `child` is unknown, no edge attaches it, the parent
1794    /// does not match, the edge carries no sample ring (it is static or
1795    /// tombstoned), or the edge is already claimed.
1796    pub fn claim(&self, child: FrameId, parent: FrameId) -> Result<EdgeWriter<'_>, ClaimApiError> {
1797        if self.detached() {
1798            return Err(ClaimApiError::ChildDetached);
1799        }
1800        if !self.arena.is_writable() {
1801            return Err(ClaimApiError::ReadOnly);
1802        }
1803        let view = self.view();
1804        let (p, _depth, edge, _gen) = view
1805            .topology()
1806            .read_frame(child)
1807            .ok_or(ClaimApiError::UnknownFrame { child })?;
1808        if edge == 0 {
1809            return Err(ClaimApiError::NoEdge { child });
1810        }
1811        if p != parent.get() {
1812            return Err(ClaimApiError::ParentMismatch {
1813                child,
1814                expected: parent.get(),
1815                actual: p,
1816            });
1817        }
1818        let eid = EdgeId(edge);
1819        // A static or tombstoned edge has no ring (`capacity == 0`); publishing to
1820        // it is a typed error, not a panic on an empty slot slice.
1821        let (Some(ring), Some(claim_rec)) = (view.ring(eid), view.claim(eid)) else {
1822            return Err(ClaimApiError::NotDynamic { child, edge: eid });
1823        };
1824        // ---- Two-phase acquire (`docs/decisions/0005` §5) --------------
1825        //
1826        // The arena CAS is the *decision*; the lock-file byte is a *lease* that
1827        // makes the holder's death observable. §6.1's literal "the lock file is
1828        // authoritative" is not implementable — two files, no atomic
1829        // cross-update, and a `HeapArena` has no lock file at all — so exactly
1830        // one of them is the linearization point, and it is this CAS.
1831        let (epoch, owner) = claim(claim_rec, self.participant)?;
1832
1833        // The CAS has landed and the lease has not been taken: this is the
1834        // one-syscall window `take_claim_lease`'s epoch re-check exists to
1835        // recover from, and the only place a reaper can be placed inside it on
1836        // purpose. Compiled out entirely without `test-hooks`.
1837        #[cfg(all(feature = "test-hooks", feature = "shm", target_os = "linux"))]
1838        if let Some(hook) = CLAIM_WINDOW_HOOK.get() {
1839            hook();
1840        }
1841
1842        #[cfg(all(feature = "shm", target_os = "linux"))]
1843        let lease = self.take_claim_lease(eid, claim_rec, epoch, owner)?;
1844
1845        // §7.1's per-edge population, writer half. This is the moment the edge
1846        // is taken up, and it is off the publish path — `push` is what must not
1847        // fault, and it now cannot, for the first lap and every lap after.
1848        #[cfg(all(feature = "shm", target_os = "linux"))]
1849        self.populate_edge_rings(eid);
1850
1851        Ok(EdgeWriter {
1852            publisher: Publisher::new(ring, claim_rec, epoch, owner),
1853            #[cfg(all(feature = "shm", target_os = "linux"))]
1854            fork_gen: self.fork_gen,
1855            #[cfg(all(feature = "shm", target_os = "linux"))]
1856            _lease: lease,
1857        })
1858    }

1860    /// Claim `child`'s edge, keeping the tree alive for as long as the writer
1861    /// lives (`docs/decisions/0017`).
1862    ///
1863    /// The scoped [`Tree::claim`] is preferable where the claim's scope is
1864    /// lexical — the borrow checker then enforces the claim's lifetime for free.
1865    /// Use this where the writer is *stored*: a node that publishes for the life
1866    /// of the process, or a binding whose handle type cannot carry a lifetime.
1867    /// See [`OwnedWriter`] for the full argument, and `docs/API.md` §2.1 for the
1868    /// rule this exists to satisfy.
1869    ///
1870    /// # Why `self: &Arc<Self>` and not `Arc<Tree>` by value
1871    ///
1872    /// By value would force a clone at every call site that already holds the
1873    /// handle, and it reads as though the tree were consumed. This spelling
1874    /// makes the refcount bump an implementation detail while keeping the real
1875    /// requirement — that the tree is *already* shared — visible in the
1876    /// signature. It also means the method is simply unavailable on a `Tree` a
1877    /// caller owns outright, which is the correct answer: they should be using
1878    /// [`Tree::claim`].
1879    ///
1880    /// # Cost
1881    ///
1882    /// Exactly [`Tree::claim`] plus one `Arc` strong-count increment, paid once
1883    /// at claim time. Nothing is added to `push`.
1884    ///
1885    /// # Errors
1886    ///
1887    /// [`ClaimApiError`], exactly as [`Tree::claim`] — this is that call with
1888    /// the tree's own handle stapled to the result.
1889    pub fn claim_owned(
1890        self: &Arc<Tree>,
1891        child: FrameId,
1892        parent: FrameId,
1893    ) -> Result<OwnedWriter, ClaimApiError> {
1894        // The one `unsafe` in this crate (`docs/decisions/0017`). `deny` rather
1895        // than `forbid` at the crate root exists so this `allow` is greppable;
1896        // `rg 'allow\(unsafe_code\)' crates/tf_tree/src` must return this line
1897        // and nothing else.
1898        #[allow(unsafe_code)]
1899        // SAFETY: the `Tree` lives inside the `Arc`'s heap allocation, and the
1900        // `Arc::clone` stored beside the writer below is what keeps that
1901        // allocation alive for as long as the writer exists. Three facts, and
1902        // all three are needed:
1903        //
1904        // 1. An `Arc`'s contents never move — the `Tree` is *in* the allocation
1905        //    the `Arc` points at, so a reference into it stays valid across
1906        //    every clone, move and send of the handle. This is a shared
1907        //    reference into a shared-only allocation: `Arc` hands out `&mut`
1908        //    only through `get_mut`/`try_unwrap`, and fact 2 makes both fail.
1909        // 2. The clone is a *strong* reference, so there is no safe way for a
1910        //    caller to move the `Tree` out from under the writer, or to drop the
1911        //    allocation while it lives.
1912        // 3. `OwnedWriter`'s two fields drop writer-then-`Arc` (declaration
1913        //    order), so the claim release lands while the arena is still mapped.
1914        //
1915        // **This extends exactly one reference — the borrow of the `Tree` — and
1916        // nothing else.** An earlier revision transmuted a whole `EdgeWriter`
1917        // instead: a composite holding a `Drop` type and an `Option<ClaimLease>`
1918        // whose field set can grow, and reinterpreting a composite is precisely
1919        // how the defect this record exists to delete happened
1920        // (`transmute::<EdgeWriter, Publisher>`, which was not a lifetime
1921        // extension at all). This form cannot express that mistake.
1922        //
1923        // **And the claim is taken *through* the extended reference**, three
1924        // lines below, which makes the pairing unstateable rather than merely
1925        // stated: the writer provably borrows the same `Tree` the `Arc::clone`
1926        // refers to, so no caller — here or later — can pair a writer claimed
1927        // from tree A with an `Arc` for tree B. That is why this is written
1928        // inline rather than as a constructor taking a writer and an `Arc`
1929        // separately, which would be a safe fn with an unchecked precondition.
1930        let tree: &'static Tree = unsafe { &*Arc::as_ptr(self) };
1931
1932        // Deliberately the same `claim` every other caller uses, rather than a
1933        // second copy of its body: the two-phase acquire above — CAS, hook
1934        // window, lease, epoch re-check — is the part of this file most likely
1935        // to be edited and least likely to survive being written twice.
1936        let writer = tree.claim(child, parent)?;
1937
1938        Ok(OwnedWriter {
1939            // Boxed for soundness — `OwnedWriter`'s *Why the writer is behind a
1940            // `Box`* section, and `just miri` if it is ever un-boxed. The
1941            // allocation is paid once, at claim time, on a path that already
1942            // does two syscalls.
1943            writer: Box::new(writer),
1944            tree: Arc::clone(self),
1945        })
1946    }

1948    /// Phase two: take the lease, then prove the record is still ours.
1949    ///
1950    /// # The epoch re-check, which §6.3 does not mention and which is required
1951    ///
1952    /// Between the CAS above and the `SETLK` here there is a one-syscall
1953    /// window. A reaper that runs inside it sees `record held ∧ lock free` —
1954    /// its exact "the holder is dead" signature — and clears the record. This
1955    /// process would then hold a lease on an edge the arena reports free, and a
1956    /// third process could claim it: two writers on one edge, which is what D7
1957    /// and A4 exist to prevent.
1958    ///
1959    /// `edge::reap` bumps the epoch *before* clearing the owner, which is what
1960    /// makes the window recoverable at all: re-reading the epoch after taking
1961    /// the lease detects the reap, and this backs out and lets the caller
1962    /// retry.
1963    #[cfg(all(feature = "shm", target_os = "linux"))]
1964    fn take_claim_lease(
1965        &self,
1966        eid: EdgeId,
1967        claim_rec: &tf_tree_core::edge::ClaimRecord,
1968        epoch: u64,
1969        owner: u64,
1970    ) -> Result<Option<ClaimLease>, ClaimApiError> {
1971        let Some(lock) = self.claim_lock.as_ref() else {
1972            // No rendezvous (a heap tree, or an `attach_shared` over an
1973            // inherited fd). The CAS alone is the claim, exactly as before —
1974            // the lease adds observability, not correctness.
1975            return Ok(None);
1976        };
1977        match lock.try_take_claim(eid.0) {
1978            Ok(tf_tree_ipc::LockAttempt::Acquired) => {}
1979            Ok(tf_tree_ipc::LockAttempt::Contended) => {
1980                // The record was free but a live process holds the lease.
1981                // Reachable only through a reaper bug or `CreatePolicy::Always`
1982                // byte aliasing; back the CAS out rather than publish beside
1983                // them.
1984                tf_tree_core::edge::release(claim_rec, owner);
1985                return Err(ClaimApiError::LeaseContended { edge: eid });
1986            }
1987            Err(_) => {
1988                tf_tree_core::edge::release(claim_rec, owner);
1989                return Err(ClaimApiError::LeaseUnavailable { edge: eid });
1990            }
1991        }
1992
1993        // Verified by `the_acquire_window_backs_out`, which places a reaper
1994        // inside the window through `CLAIM_WINDOW_HOOK` — the window is one
1995        // syscall wide and cannot be hit by racing. Mutant: `if false` here ⇒
1996        // `claim` returns `Ok` and the writer publishes onto a reaped record.
1997        if claim_rec.epoch.load(Ordering::Acquire) != epoch {
1998            // A reaper ran inside the window. Give everything back.
1999            tf_tree_core::edge::release(claim_rec, owner);
2000            let _ = lock.release_claim(eid.0);
2001            return Err(ClaimApiError::ReapedDuringClaim { edge: eid });
2002        }
2003
2004        Ok(Some(ClaimLease {
2005            lock: std::sync::Arc::clone(lock),
2006            edge: eid.0,
2007            fork_gen: tf_tree_ipc::fork::generation(),
2008        }))
2009    }

2011    /// Compile a `lookup(target, source)` path into a reusable [`crate::Plan`].
2012    ///
2013    /// # Errors
2014    ///
2015    /// [`LookupError::Disconnected`] / [`LookupError::TreeTooDeep`] as
2016    /// [`compile`].
2017    pub fn plan(
2018        &self,
2019        target: FrameId,
2020        source: FrameId,
2021    ) -> Result<tf_tree_core::Plan, LookupError> {
2022        if self.detached() {
2023            return Err(LookupError::ChildDetached);
2024        }
2025        let view = self.view();
2026        let topo = view.topology();
2027        // §7.1's per-edge population, reader half, done from `compile`'s own
2028        // edge callback — which `compile` invokes for exactly the edges it
2029        // walks. Compilation is off the query path by D3 (`Plan::at` is the hot
2030        // tier and this is not it), so the guarantee that matters — no fault
2031        // *inside* a lookup — is preserved by warming here rather than by
2032        // warming every ring in the arena at attach.
2033        //
2034        // `Tree::lookup` reaches this through `cache::with_plan`, which calls
2035        // `plan` on a miss and nothing on a hit, so a reader pays once per path
2036        // per process and the cached path is untouched.
2037        //
2038        // # Why this hangs off the callback instead of walking the returned plan
2039        //

2064    ///

2066    /// **per-edge**. `populate_hot` used to over-approximate that for the rings
2067    /// by warming the whole stamp and pose arenas, on the true-but-irrelevant
2068    /// grounds that `0004` sizes them to the declared rings exactly. The rings
2069    /// are 99.8% of a large arena, so that over-approximation was very nearly
2070    /// the entire resident cost: a process attached to a 200-edge arena that
2071    /// reads five edges was charged for two hundred, permanently.
2072    ///
2073    /// This is the correction, and the win does not expire the way a
2074    /// *used-prefix* scheme's would. A prefix scheme saves only until the ring
2075    /// laps — every slot becomes used once `head` reaches `capacity`, so at
2076    /// 10 Hz into a 16 384-slot ring the saving lasts 27 minutes and is zero
2077    /// after. Keying on *which edges this process touches* saves forever,
2078    /// because a process that never plans an edge never plans it.
2079    ///

2083    /// a `.tft` deliberately populates nothing at all — [`Tree::open_frozen`]

2087    /// quietly reversing it for every frozen reader that compiles a plan.

2496    /// Replace the `/proc` liveness heuristic with the kernel's answer (§5.1).
2497    ///
2498    /// `/proc` parsing is an *inference* with a race in it: between reading a
2499    /// pid and acting on it the process can exit and the number be reused, and
2500    /// an unreadable `/proc` entry is indistinguishable from a permission
2501    /// problem. So it fails safe — unknown means alive — which is right but
2502    /// means a dead participant is never *proven* dead.
2503    ///
2504    /// `F_OFD_GETLK` on the participant's lock byte is authoritative instead.
2505    /// A process that dies for any reason has its byte released by the kernel,
2506    /// with no cooperation and no timeout; a process that is merely `SIGSTOP`ped
2507    /// or GC-stalled still holds it, which is exactly the distinction
2508    /// `docs/PROJECT.md` §5 D17 forbids a heartbeat from making.
2509    #[cfg(all(feature = "shm", target_os = "linux"))]
2510    pub(crate) fn use_ofd_liveness(&mut self, probe: crate::open::LivenessProbe) {
2511        let own_slot = self.participant;
2512        // **One description, two holders — and the `Arc` is exactly the
2513        // lifetime convenience.** The probe arrives by value, the closure below
2514        // must own what it captures, and `Self::reap_participants` needs the
2515        // same object for the three-valued answer this closure collapses.
2516        // Nothing in a `Tree` can build a second one: `LivenessProbe::open`
2517        // wants a `Rendezvous` and a `LockFile` keeps no path. Sharing is not a
2518        // correctness property — this probe is *already* a description of its
2519        // own, which the closure's own comment below and `LivenessProbe`'s doc
2520        // comment both say, so a second one would agree about every byte
2521        // including ours; it would cost an `open(2)` and an fd and decide
2522        // nothing. See the `ofd_probe` field.
2523        let probe = std::sync::Arc::new(probe);
2524        self.ofd_probe = Some(std::sync::Arc::clone(&probe));
2525        self.liveness = Box::new(move |slot, rec| {
2526            // **Never report ourselves dead.** `F_OFD_GETLK` answers about
2527            // *conflicting* locks, so a description does not see its own — a
2528            // property `tf_tree_ipc`'s `a_holder_does_not_see_its_own_lock`
2529            // proves. This probe uses a second open file description, which
2530            // happens to make our byte visible again, but relying on that would
2531            // be relying on a detail a future refactor could remove by sharing

2547    /// Reclaim edges whose holder is provably dead (`docs/PHASE2.md` §6.3).
2548    ///
2549    /// Returns how many claims were reaped.
2550    ///
2551    /// # The predicate
2552    ///
2553    /// `record held and lease free` means the holder is dead — **or** is inside
2554    /// the one-syscall window between its CAS and its `SETLK`. That second case
2555    /// is closed from the *claimer's* side by the epoch re-check in
2556    /// [`Self::claim`], not by this loop backing off, which is strictly better
2557    /// than a grace period because there is no timing constant to tune.
2558    ///
2559    /// # Two skips that are not optional
2560    ///
2561    /// **Never judge ourselves.** `F_OFD_GETLK` reports only *conflicting*
2562    /// locks, so a description does not see its own — every edge this process
2563    /// holds reads lease-free. A literal §6.3 loop therefore revokes its own
2564    /// live writers, and A4 then correctly reports `ClaimRevoked` on the next
2565    /// push: a self-inflicted outage presenting as a spurious reap. §6.3 does
2566    /// not mention this.
2567    ///
2568    /// **Only a read-write participant may reap**, because a read-only tree
2569    /// never registered and its `participant` is the `u32::MAX` sentinel, where
2570    /// `sentinel + 1` overflows. It also has nothing to reap *with*: reaping
2571    /// writes to the arena.
2572    ///
2573    /// An unreadable lease is treated as held, which is the fail-safe direction
2574    /// (§6.2) — a false "alive" postpones recovery, a false "dead" steals an
2575    /// edge from a working process.

2577    #[must_use]

2583    ///
2584    /// The owner learns a participant died from `EPOLLHUP` on its socket, and
2585    /// therefore knows *which slot* went away. Passing it turns an `O(edges)`
2586    /// sweep of `fcntl` calls into `O(edges)` relaxed loads plus one syscall per
2587    /// edge that slot actually held, which matters because `probe_claim` is a
2588    /// syscall and an arena can hold thousands of edges.

2595    #[cfg(all(feature = "shm", target_os = "linux"))]
2596    fn reap_inner(&self, only_slot: Option<u32>) -> usize {
2597        let Some(lock) = self.claim_lock.as_ref() else {
2598            return 0; // no rendezvous, no leases, nothing provable
2599        };
2600        // A read-only tree cannot reap and cannot form an owner word.
2601        if self.participant == u32::MAX || !self.arena.is_writable() {
2602            return 0;
2603        }
2604        // Compare the *slot*, not the word. `pack_owner` is
2605        // `(epoch << 16) | (slot + 1)`, so a whole-word comparison against
2606        // `slot + 1` matches only at epoch 0 — which `claim` never produces.
2607        // A reaper making that mistake does not recognise its own claims and
2608        // revokes them.
2609        let own_slot = self.participant;
2610
2611        let view = self.view();
2612        let max_edges = view.header().max_edges;
2613        let mut reaped = 0;
2614
2615        for edge in 0..max_edges {
2616            let Some(rec) = view.claim(EdgeId(edge)) else {
2617                continue;
2618            };
2619            // The cheap filter that keeps this from being one syscall per edge:
2620            // an unclaimed edge costs a relaxed load and nothing else.
2621            let owner = rec.owner.load(Ordering::Acquire);
2622            if owner == 0 {
2623                continue;
2624            }
2625            // `u32::MAX` for a claim still in flight (the `CLAIMING` sentinel),
2626            // which is never ours and *should* be reaped: it is distinguishable
2627            // garbage a killed claimer leaves behind. A live claimer caught in
2628            // that few-instruction window is protected from the other side, by
2629            // the epoch re-check in `claim`.
2630            let owner_slot = tf_tree_core::edge::slot_of(owner);
2631            if owner_slot == own_slot {
2632                continue;
2633            }
2634            if only_slot.is_some_and(|s| owner_slot != s) {
2635                continue;
2636            }
2637            // Unreadable reads as held (§6.2): fail safe.
2638            if lock.probe_claim(edge).map_or(true, |p| p.held) {
2639                continue;
2640            }
2641            tf_tree_core::edge::reap(rec);
2642            reaped += 1;
2643        }
2644        reaped
2645    }

2647    /// Reclaim the participant records of processes the kernel says are gone
2648    /// (`docs/PHASE2.md` §3.9 and §6.3, `docs/decisions/0028` plan step 5).
2649    ///
2650    /// Returns how many records were collected. Sweeps every slot in the
2651    /// arena's participant table, applies the one reclamation predicate to
2652    /// each, and frees the record where — and only where — that predicate says
2653    /// the byte is free.
2654    ///
2655    /// # This is deliberately not owner-only
2656    ///
2657    /// `docs/PROJECT.md` §6 lists "reaping from the owner only" as a design
2658    /// smell by name and `docs/PHASE2.md` §6.3 forbids it outright, and the
2659    /// reason is concrete rather than stylistic. The owner's socket-hangup
2660    /// callback is the O(1) fast path and it cannot see five things (`0028`,
2661    /// candidate B), of which **the owner's own slot** is the one no `HUP` can
2662    /// ever cover: the owner registers itself, no socket of its own closes, and
2663    /// nothing hangs up on it. A `SIGKILL`ed owner therefore leaves a `LIVE`
2664    /// record over a byte the kernel has released — #184's wedge — and any
2665    /// *surviving* read-write participant calling this is what collects it.
2666    ///
2667    /// # One slot per process, so the sweep never reasons about two
2668    ///
2669    /// `0028` open question 3 settled that a taking-over heir keeps the slot,
2670    /// byte and record it already holds — takeover is byte 0 plus a `bind` —
2671    /// because its participant slot is baked into every claim (A3) and every
2672    /// topology guard (A2) it holds. So one process is one slot, always, and
2673    /// nothing here has to reconcile a process occupying two.
2674    ///
2675    /// # What it refuses, and how you can tell
2676    ///
2677    /// **A read-only tree reaps nothing**, and returns `0` rather than an
2678    /// error, which is [`Self::reap_dead`]'s shape and `docs/API.md` R6's
2679    /// substance taken through the door that rule's own text opens: reclaiming
2680    /// is a `compare_exchange` and a `PROT_READ` mapping answers one with
2681    /// `SIGSEGV`, so the check is what makes read-only a safety boundary; and
2682    /// [`Self::is_writable`] is public *"so a consumer can branch on capability
2683    /// instead of on an error it was going to get"*. Read-only is the consumer
2684    /// default (D18) and the Python default, so this is the ordinary case, not
2685    /// a corner. A caller that needs to tell "refused" from "nothing to
2686    /// collect" asks `is_writable()`; the two are otherwise the same `0`.
2687    ///
2688    /// **A tree with no lock file reaps nothing**, for the reason the predicate
2689    /// documents: liveness is a kernel fact about a byte (§5.1), and a heap
2690    /// tree or a directly-built `build_shared` tree has no byte to ask about.
2691    /// The probe is installed by `Open::attempt` and by nothing else.
2692    ///
2693    /// **This process's own slot is never collected.** The predicate's own
2694    /// second constraint, unconditional and evaluated first: `F_OFD_GETLK`
2695    /// reports only *conflicting* locks, so a description does not see its own,
2696    /// and a sweep that judged itself from the byte would reclaim its own live
2697    /// record the moment a refactor shared one description.
2698    ///
2699    /// **A tree detached by `fork` reaps nothing**, and what stops it is the
2700    /// crate-internal `view()` answering with the poison arena rather than a
2701    /// check here — the same single mechanism `Drop` relies on, kept single on
2702    /// purpose. The poison arena's table is empty, so every slot reads `FREE`
2703    /// and the sweep collects nothing without a syscall.
2704    ///
2705    /// # Cost
2706    ///
2707    /// Nothing on the hot path — `Plan::at` is untouched, so `docs/API.md` R2
2708    /// is unaffected. One `F_OFD_GETLK` per non-`FREE` slot that is not ours,
2709    /// and nothing at all for the others: a `FREE` word costs one `Acquire`
2710    /// load and no syscall, which is what makes the common shape free — a
2711    /// read-only joiner holds a byte and writes no record, so most slots on a
2712    /// real system are exactly that. For scale, 64 probes were measured at
2713    /// ~23-28 µs and a single probe at ~0.4 µs, against a 97.5 µs p50 attach
2714    /// (`0028` open question 4); a sweep that finds nothing to ask about costs
2715    /// neither.
2716    ///
2717    /// # The read order is a correctness property
2718    ///
2719    /// Every slot goes through `crate::open::reclamation_verdict`, which
2720    /// observes the `state` word **before** it probes the byte and carries the
2721    /// observed word into the verdict so this loop has nothing to re-read.
2722    /// `ParticipantTable::reclaim` is a `compare_exchange` against *that* word,
2723    /// so a slot that changed between the verdict and the CAS is not collected.
2724    /// Reversed — or written from `LockFile::held_participants`, which returns
2725    /// all 64 bytes in one call and makes the wrong order the natural one —
2726    /// `loom` erases a published record in 0.00 s. That is why this sweeps
2727    /// through the predicate rather than taking a holder mask first, and why
2728    /// there is exactly one predicate to sweep through.
2729    #[cfg(all(feature = "shm", target_os = "linux"))]
2730    #[must_use]
2731    pub fn reap_participants(&self) -> usize {
2732        // R6, and first: a `PROT_READ` mapping does not fault politely on a
2733        // `compare_exchange`, it delivers `SIGSEGV`.
2734        //
2735        // **One check, not two**, and unlike `reap_inner`'s pair that is a
2736        // choice with a measurement behind it. The `participant == u32::MAX`
2737        // half would catch every read-only tree here too — a read-only
2738        // attachment registers no record, so the sentinel and unwritability
2739        // arrive together — and deleting it alone leaves
2740        // `a_read_only_tree_reaps_no_participant_records` green. It is the
2741        // proxy; this is the hazard. `reap_inner` needs the sentinel for a
2742        // second reason this has not got — `slot + 1` overflows when it forms
2743        // an owner word — and a guard kept for a reason that does not apply is
2744        // the one a later reader deletes as redundant, having deleted the wrong
2745        // one.
2746        if !self.arena.is_writable() {
2747            return 0;
2748        }
2749        // No rendezvous, no lock file, no kernel fact to act on. This scopes the
2750        // *sweeper*, and only the sweeper: it says nothing about whether the
2751        // records it will judge have bytes of their own. A `build_shared`
2752        // participant in this same arena has none, and is read dead — see
2753        // `docs/decisions/0031-the-participant-record-with-no-byte.md`.
2754        let Some(probe) = self.ofd_probe.as_ref() else {
2755            return 0;
2756        };
2757
2758        let view = self.view();
2759        let table = view.participants();
2760        let slots = view.header().max_participants;
2761        let mut reaped = 0;
2762
2763        for slot in 0..slots {
2764            let Some(rec) = table.get(slot) else {
2765                continue;
2766            };
2767            // The word, then the byte, then the CAS against the word — all
2768            // three inside the predicate and `reclaim`, so this loop chooses no
2769            // ordering of its own and cannot get one wrong.
2770            if let crate::open::Reclamation::Reclaimable { observed } =
2771                crate::open::reclamation_verdict(probe, self.participant, slot, rec)
2772            {
2773                // `false` when the slot moved under us — reclaimed by a racing
2774                // sweeper, or re-occupied. Not counted, because nothing was
2775                // collected: racing reclaimers are harmless and at most one
2776                // CAS succeeds.
2777                if table.reclaim(slot, observed) {
2778                    reaped += 1;
2779                }
2780            }
2781        }
2782        reaped
2783    }

2929/// Best-effort Linux boot id folded to a `u64` (Phase 2 staleness input); `0` if
2930/// unavailable. Phase 1 stores it and does nothing else with it.
2931impl Drop for Tree {
2932    fn drop(&mut self) {
2933        // Release the participant slot on a clean exit. A slot leaked by a
2934        // *crash* is the reaper's problem (`docs/PHASE2.md` §6); this is the
2935        // orderly path, and skipping it would exhaust the table across
2936        // repeated attach/detach cycles in a long-lived arena.
2937        //
2938        // Read-only attachments never registered (they cannot write the table),
2939        // so they have nothing to release.
2940        // **A `fork` child must not release the parent's slot** — and what stops
2941        // it is `view()`, not a check here. A detached tree's `view()` returns
2942        // the poison arena, so this releases a slot in a throwaway heap arena
2943        // that names nothing. The parent's record is untouched, and the child
2944        // never stores into the unmapped page.
2945        //
2946        // An explicit `if self.detached() { return }` was written here first and
2947        // then deleted: with the poison in place it is unreachable in any way a
2948        // test can demonstrate — removing it left
2949        // `a_forked_child_runs_its_destructors_without_touching_the_parent`
2950        // green, while removing the poison turns that test's child into
2951        // `signalled 11`. Two mechanisms for one invariant, only one of them
2952        // load-bearing, is how the load-bearing one eventually gets deleted as
2953        // redundant. **Do not add the check back; keep the poison.**
2954        if self.participant != u32::MAX && self.arena.is_writable() {
2955            self.view()
2956                .participants()
2957                .release(self.participant, self.incarnation);
2958        }
2959    }
2960}

2985/// The fork generation to poison a tree against, or `None` for a backing that
2986/// survives a `fork` intact.
2987///
2988/// A [`HeapArena`] is ordinary anonymous memory: `fork` gives the child a
2989/// copy-on-write duplicate, every reference into it stays valid, and the child's
2990/// tree keeps working — divergently from the parent's, which is what `fork`
2991/// means. Poisoning that would break `multiprocessing` for single-process users
2992/// to defend against a hazard they do not have.
2993///
2994/// A mapped arena is the opposite: `MADV_DONTFORK` means the child has **no
2995/// mapping** there at all (`docs/PHASE2.md` §7.3).
2996///
2997/// Arming here rather than lazily is the load-bearing part. The handler must be
2998/// installed before any `fork` can happen, and "a shared mapping now exists" is
2999/// the earliest moment at which a `fork` could do damage. Arming on first *use*
3000/// would install it after the fork that mattered, and both processes would then
3001/// read generation 0 and agree they were the parent.
3002///
3003/// This also forces [`poison_arena`] to be built, in the parent, while
3004/// allocating is still safe. A `fork` child may have inherited a locked
3005/// allocator from a thread that no longer exists, so the detached path must not
3006/// be the thing that first allocates.
3007#[cfg(all(feature = "shm", target_os = "linux"))]
3008fn fork_gen_for(backing: &ArenaBacking) -> Option<u64> {
3009    match backing {
3010        ArenaBacking::Heap(_) => None,
3011        // A frozen mapping is `MAP_PRIVATE | PROT_READ` and deliberately *not*

3026/// Which arena a [`Tree`] reads, as one `u64`, for the plan cache's key.
3027///
3028/// **The arena, not the handle.** Two `Tree`s mapping one shared segment see
3029/// one topology and one set of static transforms, so a plan compiled through
3030/// either is correct through the other; giving them separate identities would
3031/// cost every second handle a recompile and buy no safety. Two *processes*
3032/// mapping that segment have separate caches already — the cache is
3033/// `thread_local!` — so nothing here is shared between them but the value.
3034///
3035/// The two backings answer "which arena" from different places:
3036///
3037/// * A shared segment already carries an identity: `instance_uuid`, drawn once
3038///   per `MappedArena::create` and preserved by every attach, which is exactly
3039///   the "this arena instance, as distinct from this arena *name*" question
3040///   `docs/decisions/0005` made it answer. Every handle onto one segment
3041///   agrees on it, which is the property this key wants.
3042/// * A heap arena's `instance_uuid` is all-zero on purpose (`HeapArena` is
3043///   single-process by construction, and drawing randomness there would put an
3044///   RNG in the no-`shm` dependency budget), and it **must not grow a field to
3045///   fix that**: `FORMAT_VERSION = 3` already happened. It does not need one —
3046///   a `HeapArena` is owned by exactly one `Tree`, so for that backing handle
3047///   identity *is* arena identity — and a process-local counter supplies it.
3048///
3049/// **Not the base pointer**, which is the tempting answer that adds no state:
3050/// the allocator hands the same address straight back to the next arena of the
3051/// same layout, measured here as 8 of 8 build-drop-build cycles returning one
3052/// address, so a base-pointer key would leave the entire defect standing for
3053/// sequential trees — which is what a test suite and any rebuild loop does.
3054///
3055/// A frozen `.tft` takes a counter id too, even though its header **does** carry
3056/// the `instance_uuid` of the live arena it was frozen from — measured, by
3057/// freezing one arena to two paths and reading both back: same uuid, non-zero.
3058/// Two files frozen from one arena at different times therefore share that id
3059/// and *differ in content*, so it is not an identity for the image. Two
3060/// `open_frozen` calls on one path also compile separately, which costs a
3061/// compile and cannot be wrong.
3062fn cache_scope_for(backing: &ArenaBacking) -> u64 {
3063    // **A match on the variants, not a predicate.** The question here — "does
3064    // this backing carry an identity that outlives the handle?" — is one no
3065    // existing predicate answers. `is_shared` is the one it was first spelled
3066    // as, and its own doc says it means "whether a peer can *mutate* it": the
3067    // participant table, the claim protocol and reaping hang off that answer,
3068    // and this does not. `is_frozen`'s doc, three lines below it, is the
3069    // warning that applies verbatim — a predicate answering a question next to
3070    // the one it was asked is one backing variant away from being wrong. Two
3071    // concrete ways, both live today:
3072    //
3073    // * Give `Frozen` the *other* defensible `is_shared` answer — other
3074    //   processes really may map the same `.tft`, which is what that method's
3075    //   summary line says — and every frozen tree starts keying on the header's
3076    //   `instance_uuid`. Measured: two files frozen from one live arena carry
3077    //   the **same non-zero** uuid, so two `.tft`s that differ in content would
3078    //   share a cache scope. That is issue #196 again, in the offline path.
3079    // * Add a mapped-but-immutable backing (a file-backed image, a sealed
3080    //   snapshot). `is_shared` false hands every handle its own id, silently
3081    //   costing the recompile that
3082    //   `cache::tests::two_handles_on_one_shared_arena_share_their_plans`
3083    //   exists to prevent; `is_shared` true reads a uuid that may not identify
3084    //   the *contents*, which is the bug above.
3085    //
3086    // Matched here rather than behind a new `ArenaBacking::instance_identity`
3087    // method because there is exactly one caller and the compile error is
3088    // identical either way — but written this way it lands on the paragraph
3089    // that says what the new variant has to answer, instead of on a signature
3090    // three hundred lines away.
3091    let uuid: Option<[u8; 16]> = match backing {
3092        // Single-process by construction: the handle *is* the arena.
3093        ArenaBacking::Heap(_) => None,
3094        #[cfg(all(feature = "shm", target_os = "linux"))]
3095        ArenaBacking::Mapped(_) => Some(ArenaView::new(backing.as_dyn()).header().instance_uuid),
3096        // The header's uuid identifies the arena this image was taken from, not
3097        // the image. See the closing paragraph of this function's doc.
3098        #[cfg(all(feature = "shm", target_os = "linux"))]
3099        ArenaBacking::Frozen(_) => None,
3100    };
3101    // `create` always draws one, so the all-zero arm is defence rather than a
3102    // reachable branch: an all-zero id read as an identity would make every
3103    // shared arena the same arena, which is the defect this function exists to
3104    // remove.
3105    let Some(uuid) = uuid.filter(|u| *u != [0u8; 16]) else {
3106        return next_local_scope();
3107    };
3108    let lo = u64::from_le_bytes([
3109        uuid[0], uuid[1], uuid[2], uuid[3], uuid[4], uuid[5], uuid[6], uuid[7],
3110    ]);
3111    let hi = u64::from_le_bytes([
3112        uuid[8], uuid[9], uuid[10], uuid[11], uuid[12], uuid[13], uuid[14], uuid[15],
3113    ]);
3114    // The halves are independent uniform bytes, so their xor is uniform in 64
3115    // bits; forcing the top bit costs one bit of that and buys a space disjoint
3116    // from the counter's, so a heap tree and a shared tree can never collide by
3117    // arithmetic accident and no argument about the odds is needed.
3118    (lo ^ hi) | (1 << 63)
3119}

3121/// A process-unique id for an arena that carries no `instance_uuid`.
3122///
3123/// Process-*local* is the whole requirement: the cache it keys is
3124/// `thread_local!`, so a value only ever meets values minted by this process.
3125///
3126/// The same shape as `tf_tree_c::publisher`'s `NEXT_TOKEN`, and for the same
3127/// reason: an identity that can be recycled turns the comparison that uses it
3128/// into a coin flip, and a `u64` counter is the cheapest thing that cannot be.
3129fn next_local_scope() -> u64 {
3130    static NEXT: AtomicU64 = AtomicU64::new(1);
3131    // Relaxed: uniqueness is `fetch_add`'s own guarantee and nothing is
3132    // published through this counter, so there is no other thread's writes for
3133    // it to order.
3134    let n = NEXT.fetch_add(1, Ordering::Relaxed);
3135    // Stays out of the shared half of the space: 2^63 trees at one per
3136    // nanosecond is 292 years.
3137    debug_assert!(n < 1 << 63);
3138    n
3139}

3203/// **The liveness predicate** — the single seam where "is participant `slot`
3204/// still running?" is answered, injected into
3205/// [`tf_tree_core::topology::TopoLockView::acquire`].
3206///
3207/// `tf_tree_core` deliberately does not answer this: it is `no_std` and
3208/// `docs/PHASE2.md` §2 forbids it a syscall dependency, so the arena lock takes
3209/// the answer as a parameter and this is what supplies it.
3210///
3211/// # This is the interim implementation, and it is meant to be replaced
3212///
3213/// `docs/PHASE2.md` §5.1 is explicit: **the OFD lock file is authoritative and
3214/// these records are advisory** — "any code deciding liveness from `state` or
3215/// `heartbeat` is a bug". §6.1 explains why: a `SIGSTOP`ped or GC-stalled
3216/// process still holds its kernel lock, so `F_OFD_GETLK` reporting the byte free
3217/// is a *fact* about death rather than a heuristic about it, and the whole
3218/// zombie class disappears. The lock file is not built yet.
3219///
3220/// Until it is, this implements §6.2's `/proc` predicate, which is the same
3221/// question asked less reliably. When the lock file lands, replacing the body of
3222/// this function with an `F_OFD_GETLK` on `PARTICIPANT_BASE + slot` is the entire
3223/// change: nothing in `tf_tree_core` and nothing else in this crate knows how
3224/// the answer is reached.
3225///
3226/// # It fails safe, in every branch
3227///
3228/// Every path that cannot *prove* death returns `true`. A false negative steals
3229/// the topology lock from a live mutator and lets two writers race one scratch
3230/// block; a false positive only makes the caller retry. §6.2 states the
3231/// asymmetry and the default it demands.
3232/// Is the process that owns this participant record still running?
3233///
3234/// The per-record half of [`participant_is_alive`], in the shape A8's rescue
3235/// path needs: it is handed a record, not a slot index.
3236///
3237/// A slot that is not `LIVE` is reported dead — that covers a released slot and
3238/// one whose registrant died partway through filling it in, since `RESERVED` is
3239/// held for a handful of instructions by a healthy process
3240/// (`docs/PHASE2.md` §11.3, `attach.after_slot_assigned_before_publish`).
3241///
3242/// `Unreadable` resolves to **alive**, and every branch is chosen the same way:
3243/// a false "dead" lets a rescuer take an entry from a running process, which is
3244/// corruption; a false "alive" only delays recovery. [`alive_given`] is where
3245/// the bias is applied, and two of its arms exist because two branches once
3246/// produced the other direction.
3247fn record_is_alive(rec: &tf_tree_core::ParticipantRecord) -> bool {
3248    use core::sync::atomic::Ordering;
3249    if tf_tree_core::participant::state_of(rec.state.load(Ordering::Acquire))
3250        != tf_tree_core::participant::LIVE
3251    {
3252        return false;
3253    }
3254    let pid = rec.pid.load(Ordering::Relaxed);
3255    let start_time = rec.start_time.load(Ordering::Relaxed);
3256    alive_given(start_time, read_start_time(pid), proc_answers_here())
3257}

3259/// Turn a record's stored `start_time` and what `/proc` said into a verdict.
3260///
3261/// Both host facts arrive as parameters rather than as reads, because both are
3262/// things a test cannot arrange: whether `/proc` answers is a property of the
3263/// machine the suite runs on, and staging pid reuse means exhausting the pid
3264/// space. Passing them in is what makes the bias below assertable instead of
3265/// merely stated.
3266fn alive_given(stored_start_time: u64, probe: ProcStartTime, proc_answers: bool) -> bool {
3267    match probe {
3268        // The registrant could not read its own start time and stored
3269        // `UNKNOWN_START_TIME`, so there is nothing here to compare against.
3270        // Comparing anyway is false for every real start time, so the first
3271        // reader that *can* read `/proc` reports a running process dead — and it
3272        // does not even degrade to a bare-pid check, which would at least be
3273        // conservative. It inverts.
3274        ProcStartTime::Known(_) if stored_start_time == UNKNOWN_START_TIME => true,
3275        // PID reuse: same number, different process. Not our participant.
3276        ProcStartTime::Known(st) => st == stored_start_time,
3277        // Death, but only as read from a host that would have shown us the
3278        // entry. On one that answers `ENOENT` for every pid, a missing entry
3279        // says nothing and every participant in the arena would read dead.
3280        ProcStartTime::NoSuchProcess => !proc_answers,
3281        ProcStartTime::Unreadable => true,
3282    }
3283}

3285/// Build the liveness predicate for an arena, folding in the one-time reboot
3286/// check.
3287///
3288/// If the arena's boot id is known and differs from this host's, the segment
3289/// outlived a reboot: every pid in it refers to a process from a previous boot,
3290/// so nothing in it is alive and no per-record check could discover that. When
3291/// either id is unknown the comparison is skipped — treating "unknown" as
3292/// "different" would declare every participant dead, the false negative this
3293/// must never produce.
3294fn liveness_for(arena_boot: [u8; 16]) -> BoxedLiveness {
3295    let host = *host_boot_id();
3296    if arena_boot != [0u8; 16] && host != [0u8; 16] && arena_boot != host {
3297        return Box::new(|_, _| false);
3298    }
3299    Box::new(|_slot, rec| record_is_alive(rec))
3300}

3303    participants: &tf_tree_core::ParticipantTable<'_>,
3304    slot: u32,

3322    };

3329///

3335///
3336/// A process genuinely started in tick 0 of the boot collides with the sentinel

3341/// Would this host tell us that some other process exists?
3342///
3343/// A `/proc` that is not mounted — a `chroot` without one, a stripped container
3344/// — fails **every** open with `ENOENT`, the same errno a genuinely dead pid
3345/// produces and indistinguishable from it at the call site. Reading our own
3346/// entry settles which it is: this process is running by construction, so if
3347/// `/proc/self/stat` is not there then `/proc` is not there, and an `ENOENT`
3348/// about anybody else proves nothing at all.
3349///
3350/// **Latched on a decisive answer only**, because the answer is a property of the
3351/// host rather than of the pid being asked about, and the callers are the
3352/// liveness predicate — run under the topology lock, and once per claim per reap
3353/// sweep. `Ok` latches "this host answers"; `ENOENT` latches "it does not",
3354/// which is the genuine no-`/proc` host and is correct forever there. **Any
3355/// other error is indecisive and is deliberately not latched**: `ENOMEM`, an LSM
3356/// or seccomp denial, or a bind-mount race during startup would otherwise make
3357/// one transient failure permanent, and permanently answering "cannot answer"
3358/// means this process can never prove a death again — the reap sweep stops
3359/// reclaiming slots and the topology lock stops being stealable, so a momentary
3360/// error becomes a lasting loss of recovery. It is the safe direction and it is
3361/// still the wrong trade. An indecisive call resolves to alive and re-probes
3362/// next time.
3363///
3364/// The steady-state cost is unchanged and is zero syscalls: one `stat` on the
3365/// first liveness question, then a relaxed atomic load, on every host that has a
3366/// `/proc` and equally on every host that has none.
3367///
3368/// The residual is a `/proc` unmounted *after* a successful first question, which
3369/// leaves a latched `true` and the misreading this exists to prevent. That is the
3370/// behaviour before the probe existed, on a host doing something no supported
3371/// deployment does, and covering it would put a syscall back on the predicate's
3372/// path.
3373///
3374/// **`hidepid=2` is out of scope by dependency, not by accident.** It hides
3375/// another user's entries behind the same `ENOENT`, which nothing here can
3376/// distinguish — but `docs/PHASE2.md` §3.10 makes participants same-user by
3377/// construction, so a hidden entry cannot belong to one. That is the trust model
3378/// carrying weight on a correctness path, and it is named here because it is
3379/// named nowhere else.
3380fn proc_answers_here() -> bool {
3381    /// Not yet asked, or asked and answered indecisively.
3382    const UNASKED: u8 = 0;
3383    /// `/proc/self/stat` was readable: an `ENOENT` about anyone else is real.
3384    const ANSWERS: u8 = 1;
3385    /// `/proc/self/stat` was absent: no `ENOENT` here proves anything.
3386    const SILENT: u8 = 2;
3387
3388    static HOST: AtomicU8 = AtomicU8::new(UNASKED);
3389    match HOST.load(Ordering::Relaxed) {
3390        ANSWERS => true,
3391        SILENT => false,
3392        _ => match latch_for(&std::fs::metadata("/proc/self/stat")) {
3393            Some(true) => {
3394                HOST.store(ANSWERS, Ordering::Relaxed);
3395                true
3396            }
3397            Some(false) => {
3398                HOST.store(SILENT, Ordering::Relaxed);
3399                false
3400            }
3401            None => false,
3402        },
3403    }
3404}

3419/// The outcome of asking `/proc` when a process started.
3420///
3421/// Three cases, not two: "no such process" is the only one that can prove death,

3426/// *Can* prove it, and does not on its own. `NoSuchProcess` is what the read
3427/// saw, not a verdict: [`proc_answers_here`] is the second fact it needs, and

3431    /// Field 22 of `/proc/<pid>/stat`, in clock ticks since boot.
3432    Known(u64),
3433    /// There was no entry — `ENOENT`.

3435    /// There might be; `/proc` would not say.
3436    Unreadable,

3449/// Field 22 out of one `/proc/<pid>/stat` line, in clock ticks since boot.
3450///
3451/// Field 2 is `comm`, parenthesised and free to contain spaces *and*
3452/// parentheses, so the scan starts after the **last** `)` — the parsing trap
3453/// `docs/PHASE2.md` §5.1 calls out by name. After it the fields are state(3),

3477/// it useful — that two hosts, or one host across a reboot, do not collide. A
3478/// stale segment surviving a reboot is precisely what this detects.
3479fn boot_id() -> [u8; 16] {
3480    let Ok(text) = std::fs::read_to_string("/proc/sys/kernel/random/boot_id") else {
3481        return [0u8; 16];
3482    };
3483    let mut out = [0u8; 16];
3484    let mut nibbles = text.trim().bytes().filter_map(|b| match b {
3485        b'0'..=b'9' => Some(b - b'0'),
3486        b'a'..=b'f' => Some(b - b'a' + 10),
3487        b'A'..=b'F' => Some(b - b'A' + 10),
3488        _ => None, // the dashes
3489    });
3490    for byte in &mut out {
3491        let (Some(hi), Some(lo)) = (nibbles.next(), nibbles.next()) else {
3492            return [0u8; 16]; // malformed: report "unknown" rather than partial
3493        };
3494        *byte = (hi << 4) | lo;
3495    }
3496    out
3497}

3499/// This process's start time in clock ticks since boot (`/proc/self/stat` field
3500/// 22), or `None` if this host would not say.
3501///
3502/// Paired with the PID this is a **reuse-proof** process identity
3503/// (`docs/PHASE2.md` §1, A7 and §5.1): PIDs wrap, and a reaper that trusted a
3504/// bare PID could conclude a long-dead participant is alive because an unrelated
3505/// process now holds its number.
3506///
3507/// **`Option`, where this used to return `0` on failure.** A registrant that
3508/// cannot read its own start time has no identity to publish, and making the
3509/// caller name what it writes instead — [`UNKNOWN_START_TIME`] — is what stops
3510/// the sentinel being mistaken for a start time. It had been one: a `0` written
3511/// here compares unequal to every real start time, so the first reader that
3512/// could read `/proc` declared the registrant dead while it was running.
3513///
3514/// Not cached. It is constant for a process, but a `fork`ed child's differs from
3515/// its parent's, and a cache would hand the child the parent's value to register
3516/// under — reintroducing exactly the mismatch above.
3517fn process_start_time() -> Option<u64> {
3518    parse_start_time(&std::fs::read_to_string("/proc/self/stat").ok()?)
3519}

3526/// # Both fields are private, and that is the change rather than the status quo
3527///
3528/// They were `pub`, which promised that this wrapper is *exactly* the pair
3529/// `(error, tree)` forever — a promise nothing needed: the only construction
3530/// site in the workspace is [`Tree::describe`], and the only use is `Display`.
3531/// `docs/API.md` §R5 makes the prose layer explicitly separate from the error
3532/// type, so a caller who wants the [`LookupError`] back holds the one it passed
3533/// in; it is `Copy`.
3534///
3535/// The `'a` is correct under §2.1 and is not the [`EdgeWriter`] case: this is a
3536/// per-format-call borrow that lives to the end of the `write!` it appears in,
3537/// like a `std::fmt::Arguments`. Storing one in a struct is not something a
3538/// user has any reason to do, and `Tree::describe`'s signature is what stops
3539/// them trying.
3540pub struct Described<'a>(LookupError, &'a Tree);

3542impl fmt::Display for Described<'_> {
3543    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
3544        let tree = self.1;
3545        match self.0 {
3546            // **It cannot name the frame that was asked for, and it can name
3547            // the ones that exist.** The error carries a BLAKE3 prefix and
3548            // BLAKE3 does not invert, so the hash is all this arm has of the
3549            // *request* — but `Described` holds the `&Tree`, and "what is
3550            // actually in here" is the question an operator reading this is
3551            // about to ask next. Naming that costs one walk of a table this
3552            // process has already mapped.
3553            //
3554            // **Bounded at eight, and sorted — and the bound is on the *text*,
3555            // not on the allocation.** An earlier revision of this comment
3556            // justified the truncation with "unbounded, a `Display` on a
3557            // 10 000-frame tree would allocate 10 000 `String`s", which is
3558            // false: `Tree::frames` allocates one `String` per frame and sorts
3559            // all of them *before* the `truncate` below ever runs, so the
3560            // allocation is 10 000 either way. What eight buys is a readable
3561            // error line — an operator scanning a log wants a sample of the
3562            // namespace, not a dump of it.
3563            //
3564            // Paying that allocation is a deliberate accept, not an oversight:
3565            // this is `Display` on an error, reached once per failed lookup by a
3566            // process that is already about to log or exit, and the frame table
3567            // is memory this process has mapped. Making it genuinely bounded
3568            // means a bounded-`k` selection over borrowed `&str`s out of the
3569            // arena rather than `Tree::frames`' owned `Vec<String>`, which is a
3570            // different method with different unsafe-free borrow plumbing; it is
3571            // recorded as a follow-up rather than smuggled into an error-message
3572            // change. Sorted, so two runs of the same failure print the same
3573            // list — `Tree::frames`' id order does not promise that across
3574            // processes that interned in different orders.
3575            LookupError::UnknownFrame { hash } => {
3576                write!(f, "unknown frame (name hash {hash:#018x})")?;
3577                const SHOWN: usize = 8;
3578                match tree.frames() {
3579                    // A tree with no frames is a different situation and gets a
3580                    // different sentence: "known frames: (none)" reads as a
3581                    // broken lookup, when what happened is that no publisher has
3582                    // interned anything yet — the case the wait exists for.

3585                        "; this tree has no frames yet, so no publisher has \
3586                         declared anything into it. Wait for one with \
3587                         Tree::await_frames, or declare the frame on the \
3588                         TreeBuilder that creates the arena"
3589                    ),
3590                    Ok(mut names) => {
3591                        let total = names.len();
3592                        names.sort_unstable();
3593                        names.truncate(SHOWN);
3594                        f.write_str("; this tree has ")?;
3595                        for (i, n) in names.iter().enumerate() {
3596                            if i > 0 {
3597                                f.write_str(", ")?;
3598                            }
3599                            f.write_str(n)?;
3600                        }
3601                        if total > SHOWN {
3602                            write!(f, ", … ({total} total)")?;
3603                        }
3604                        write!(
3605                            f,
3606                            ". If the name is spelled right, its publisher has \
3607                             not declared it yet: wait with Tree::await_frames, \
3608                             or declare it on the TreeBuilder that creates the \
3609                             arena"
3610                        )
3611                    }
3612                    // `Tree::frames` fails only for `ChildDetached`, and that is
3613                    // worth saying: every name would read absent in a fork
3614                    // child, so the frame list would be a lie rather than a
3615                    // short answer.
3616                    Err(_) => write!(
3617                        f,
3618                        "; this tree was opened before a fork() and is being \
3619                         used in the child, so it can name nothing"
3620                    ),
3621                }
3622            }
3623            LookupError::Disconnected {
3624                target,
3625                source,
3626                cut_at,
3627            } => write!(
3628                f,
3629                "no path from {} to {}: disconnected at {}",
3630                tree.frame_name(target),
3631                tree.frame_name(source),
3632                tree.frame_name(cut_at),
3633            ),
3634            LookupError::TreeTooDeep { depth } => {
3635                write!(f, "path depth {depth} exceeds the maximum of {MAX}", MAX = tf_tree_core::MAX_DEPTH)
3636            }
3637            LookupError::NoData { edge } => {
3638                write!(f, "no samples on {}", tree.edge_name(edge))
3639            }
3640            LookupError::Extrapolation {
3641                edge,
3642                requested,
3643                oldest,
3644                newest,
3645            } => write!(
3646                f,
3647                "lookup on {} would extrapolate: requested {requested} ns, history [{oldest}, {newest}] ns",
3648                tree.edge_name(edge),
3649            ),
3650            LookupError::SlotRecycled { edge } => {
3651                write!(f, "the ring on {} lapped the reader mid-read", tree.edge_name(edge))
3652            }
3653            LookupError::SlotContended { edge } => {
3654                write!(f, "a slot on {} stayed contended too long", tree.edge_name(edge))
3655            }
3656            LookupError::TopologyChanged { plan, current } => write!(
3657                f,
3658                "plan is stale: compiled at topology generation {plan}, current is {current} (re-plan)",

3660            LookupError::TimeDomainMismatch { expected, got } => write!(
3661                f,
3662                "time-domain mismatch: plan expects domain {expected}, query supplied {got}",

4102    /// **`ReadOnly` is checked in the same test, on both**, because a refusal
4103    /// that also broke the reader path would pass an assertion that only looked

4108    #[cfg(all(feature = "shm", target_os = "linux"))]
4109    #[test]
4110    fn a_read_write_attach_over_a_descriptor_is_refused_on_both_entry_points() {

4112            .static_edge("a", "b", &Iso3::IDENTITY)
4113            .build_shared("tf_tree-attach-refusal-test")
4114            .expect("build a shared arena");
4115        let dup = || {
4116            owner
4117                .shared_fd()
4118                .expect("a shared tree has a segment fd")
4119                .try_clone_to_owned()
4120                .expect("dup the segment fd")
4121        };

4124            Tree::attach_shared(dup(), AttachMode::ReadWrite).err(),
4125            Some(ShmError::ReadWriteNeedsRendezvous),
