## [0.0.5] — 2026-08-29 (the entry paths that need no toolchain)

### Added

- `tf_tree_ipc::proc_self_pid` and `self_pid_ns_inode` (#263).
- `tf_tree_core::crash::ENV_VAR` and `crash::maybe_abort`; cargo features `pure-hash` (`tf_tree`, `tf_tree_core`) and `crash-points` (`tf_tree_core`).
- `IngestOptions::max_record_bytes` and `IngestError::RecordTooLarge` (0010).
- `just owner-migration`, `shm_torture --crash-points`, `just two-processes`, `just control-loop`, `just interp-accuracy`.
- `doctor --exit-code[=error|warn]`; bare `--exit-code` still means `error`.
- Crash-matrix sites and tests for every row of PHASE2 §11.3.
- `tf_tree.ingest_bag`, `Tree.source`, and a `Tree.freeze` that records provenance (0046).
- Prebuilt `tf_tree` CLI binaries on GitHub Releases (four Linux targets).
- Recovery from C: `tft_tree_open_named`, `tft_tree_owner_lost`, `tft_tree_inherit_ownership`, `tft_tree_reap_dead` (0044).
- `tf_tree_ipc::Session::ownership_held`.
- Python: `build`/`open(create=)` accept a topology config text as well as edge pairs (0041); `Plan.at_extrapolating` gains `layout=` and an `_into` form; both bindings reach the time domain and extrapolation (0038, 0039).
- Every core error type implements `Display` and `core::error::Error` (0040).
- `Tree::inherit_ownership` and `Tree::owner_lost` (PHASE2 §3.5, 0037).
- `Plan::at_extrapolating` and `Extrapolated` (0039).
- A tagged sibling for every query shape, and `Tree::lookup_tagged` (0038).
- `docs/API.md` §8, the real-time envelope.
- Per-publisher clock offset and a `TFT004` that reads it (0036).
- `LockFile::try_take_topology` / `release_topology` (#213).
- `tf_tree_py` `pure-hash` passthrough and `just py-cross-check` (#180).
- `just artifact-versions` and `just msrv` read the five crates.io front pages (#238).

### Changed

- `Tree::inherit_ownership` takes `&self`.
- `Plan::at_many` returns `LookupError::BufferTooSmall` instead of panicking on a short buffer.
- `Tree::owner_lost` answers "the arena has no owner", not "my socket is dead" (0043).
- An exact query returns the pose of the stamp it named, or refuses.
- `tf_tree tree`'s `age(ms)` is measured against a real clock.
- A killed publisher's claims are revoked by the owner, so a restarted node can take its edges back.
- `TFT009` reports a publisher that has stopped.
- `doctor`'s zero-counter skip reason names the read-only-participant cause.
- `EdgeWriter::push` documents that the stamp's domain is unchecked.
- `README.md` is restructured around evaluating and installing; `0016` is withdrawn.

### Changed — breaking

- `Iso3` is 56 bytes at `align(8)`, not `align(64)`, and `_pad` is gone (0042). Migration: stop matching on `_pad` or assuming `size_of::<Iso3>() == 64`.
- `ClaimRecord::last_push_nanos` is now `clock_offset_nanos` and holds `wall clock - stamp` (#273, 0036). Migration: rename the field.
- `OpenOutcome::TookOver` and `OpenError::TakeoverUnsupported` are deleted (0037). Migration: drop those match arms; use `Tree::inherit_ownership`.
- `Open::already_attached`, its takeover arm and `Open::register_any` are deleted (#275, 0037). Migration: use `Session::take_over_ownership`.
- `ReparentError::LockContended::owner_slot` is `Option<u32>`; `ReparentError` gains `TopologyLease`; `LockRole` gains `Topology` (#213, 0029). Migration: handle the new variants and the `Option`.
- `MAX_DEPTH` is 32 and bounds the compiled plan; new `MAX_PATH_EDGES` = 64 bounds the raw walk (#251, 0034). Migration: re-check code that relied on 16.
- `self_comm` returns `[u8; 16]`; `Identity` gains `pid_ns_inode: u64` and `name` narrows to `[u8; 16]` (#239, 0033). Migration: adjust widths and struct literals.
- `IpcError::ArenaHeldButUnreachable` gains `ownership_held: bool` (#257). Migration: update exhaustive patterns.

### Fixed

- `Guard`'s packed search cursor went inert past 2^32 pushes.
- `TFT016` no longer advises raising a limit nothing spends.
- `Tree::reparent` no longer steals the topology lock from a live mutator that `/proc` misreports (#213, 0029).
- A `Tree::lookup` that cannot be planned no longer recompiles on every call (#259).
- `Tree::plan` no longer copies a `Plan`-sized array three times (#264).
- `TFT014` no longer flags a healthy participant in another PID namespace (#239, 0033).
- Stopping and continuing an owner (Ctrl-Z, `gdb -p`) no longer strands its arena (#260).
- A creator takes participant slot 0 atomically (#201, 0035).
- A stamp far from the origin no longer overflows `plan::subdivide` or the interpolation parameter (#247).
- `Extrapolated::by_ns` no longer reports `0` for a pose the fold invented.
- Six Python docstrings no longer carry rustdoc intra-doc links.
- Nine defects in the release-archive path.
- Documentation corrections: `tf_tree_math` Miri claim, `LookupError` `Error` claim on crates.io, runbook `tf_tree serve`, PHASE3 Appendix B, `0003` amendments, committed build output (#246), `just lint` clippy-pass count.
