## [0.0.2] — 2026-08-17 (wheels, no sdist)

### Fixed

- `tf_tree_py` compiles on macOS and Windows; `open_arena` has a non-Linux arm that refuses with a message naming the platform.
- `[tool.maturin] include` names `LICENSE-APACHE`, `LICENSE-MIT` and `NOTICE`, so the sdist carries the files its `PKG-INFO` declares.

### Note

- 0.0.2 published wheels without an sdist (PyPI rejected it); a platform the wheels do not cover has no source fallback until 0.0.3.
- 0.0.1 is a crates.io-only release; no wheel exists for it.
