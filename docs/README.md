# Docs

This project keeps documentation lean. The base template ships with:

- [`decisions/`](./decisions/) — architectural decision records. Every
  significant architectural change starts here as a `draft`. See
  [`decisions/README.md`](./decisions/README.md) for the lifecycle.

User-facing documentation (Diátaxis: tutorials, how-tos, reference,
explanation) is an opt-in extension; see the "Opt-in extensions" section of
the decisions README for the recipe.
